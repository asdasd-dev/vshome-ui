# ControlList

Список настроек: каждая строка — подпись слева и элемент управления справа, под ними по желанию дополнение во всю ширину. `ControlList` — контейнер `ul`, `ControlRow` — строка.

## Когда применять

- Группа переключателей: «Ночной режим стены», «Звук уведомлений».
- Свет на стене: лампа с [Switch](#/c/Switch) и [Slider](#/c/Slider) яркости под ней.
- Настройки сайта в [Sheet](#/c/Sheet): тема, вид, уведомления.

## Когда не применять

- Строки с данными, а не управлением — [List](#/c/List) или [KeyValue](#/c/KeyValue).
- Поля формы с подписями сверху — [Field](#/c/Field).
- Одна настройка — [Switch](#/c/Switch) с `label` сам по себе.

## Анатомия

1. Строка — сетка из двух колонок, линия `--vs-line` сверху, отступ `--vs-space-3` сверху и снизу.
2. `label` — слева, сжимается и переносится.
3. `control` — справа, прижат к краю: [Switch](#/c/Switch), [Segment](#/c/Segment), [Button](#/c/Button) `sm`.
4. `children` — третья строка во всю ширину: [Slider](#/c/Slider), подсказка.

## Состояния

Своих состояний нет: включено, выключено и недоступно показывает элемент в `control`. Дополнение в `children` можно показывать только при включённом переключателе.

## В киоске

Отдельных правил нет: внутри `.vs-kiosk` отступы и шрифт растут на `--vs-scale`, подпись и элемент остаются на тех же местах. На стене список кладут в [Tile](#/c/Tile).

## Доступность

- `label` строки — видимый текст, он не связан с элементом. Передавайте подпись и самому элементу: `<Switch label="Баня" />`, иначе скринридер услышит «переключатель» без имени.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Одна настройка — одна строка | Два переключателя в одном `control` |
| Яркость — в `children` под переключателем | Слайдер в `control` справа |
| Подпись дублировать в `label` элемента | Полагаться на текст строки как на имя переключателя |
| Вид менять через токены дизайн-системы | Убирать линии своим `.vs-control-row { border: 0 }` |
