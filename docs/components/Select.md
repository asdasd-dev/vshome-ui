# Select

Выпадающий список для выбора одного значения из многих. Подпись `label` всегда видна над полем, список открывается во всплывающем окне с галочкой у выбранного.

## Когда применять

- Вариантов больше четырёх или подписи длинные: магазин в Ленте («Лента на Победы», «Лента в Мега»), проект задачи на доске.
- Настройка в форме или шторке, которую меняют редко: «Комната» у нового устройства, «Канал Mattermost» для уведомлений.

## Когда не применять

- Два–четыре коротких варианта на виду — [Segment](#/c/Segment).
- Фильтр списка, где полезно видеть все варианты и счётчики — [ChipGroup](#/c/Chip).
- Выбор с пояснениями к каждому варианту — [RadioGroup](#/c/Checkbox).
- Список действий над объектом — [ContextMenu](#/c/ContextMenu).
- Свободный ввод или поиск по сотням товаров — [TextField](#/c/Field) с `type="search"`.

## Анатомия

1. Подпись `label` — мелкий серый текст над полем, как у [Field](#/c/Field); `hideLabel` прячет её визуально, но оставляет скринридеру.
2. Поле — текущее значение (обрезается многоточием) и стрелка `chevron-down`.
3. Всплывающий список не уже поля, строки по 44 px × масштаб.
4. Галочка `--vs-accent` у выбранной строки.
5. Подсказка `hint` и ошибка `error` под полем — как у [Field](#/c/Field).

## Размеры

- `size="md"` (по умолчанию) — поле формы, высота 40.
- `size="sm"` — плотная панель фильтров и сортировки над списком: высота 32, текст 14. Подпись в таком ряду обычно прячут `hideLabel` и ставят рядом [Text](#/c/Text) `caption`.

## Состояния

- Фокус — кольцо `--vs-focus-ring` вокруг поля.
- Открыт — список под полем, подсвеченная строка `--vs-accent-tint`; касание мимо списка закрывает только список: [Sheet](#/c/Sheet), внутри которого стоит Select, остаётся открытым.
- `disabled` — прозрачность 50%, курсор «нельзя», список не открывается.
- `error` — текст ошибки под полем, `aria-invalid` у поля.
- Загрузки нет: на время запроса выключайте поле.

## В киоске

Отдельных переменных нет: высота поля и строк списка заданы через `--vs-scale` и в `.vs-kiosk` растут в 1,25 раза.

## Доступность

- `label` связан с полем, скринридер читает «Магазин, Лента на Победы, всплывающий список».
- `hint` и `error` подключены к полю через `aria-describedby`.
- Управление с клавиатуры: стрелки, `Enter`, `Esc`, поиск по первым буквам.
- Подписи вариантов — только строки: иконки в пунктах не поддерживаются.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Подпись-существительное: «Магазин», «Проект» | «Выберите…» в `label` |
| Варианты в понятном порядке: по алфавиту или по частоте | Случайный порядок из ответа API |
| [Segment](#/c/Segment), если вариантов два | Select «Да / Нет» |
| Менять вид через токены в дизайн-системе | `.shop .vs-select__trigger { … }` на сайте |
