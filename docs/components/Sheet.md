# Sheet

Шторка поверх страницы: шапка с заголовком и крестиком, прокручиваемое тело, подвал с действиями. На широком экране — окно по центру, на ширине до 760px — панель снизу, которую можно смахнуть.

## Когда применять

- Подробности объекта без ухода со страницы: карточка задачи на доске, журнал деплоя на дашборде.
- Короткая форма: комментарий к задаче, переименование, подтверждение необратимого действия.
- Подробности встречи или агента на «Столе» по касанию плитки.

## Когда не применять

- Короткое уведомление о результате — [Toast](#/c/Toast).
- Несколько действий над объектом без формы — [ContextMenu](#/c/ContextMenu).
- Выбор одного значения из списка — [Select](#/c/Select).
- Подробности, которые можно показать на месте — [Disclosure](#/c/Disclosure).
- Отдельная страница со своим адресом — переход по [Link](#/c/Link).

## Анатомия

1. Подложка — затемнение с размытием, касание пальцем закрывает шторку.
2. Ручка — полоска сверху, только в мобильном виде.
3. Шапка — `head` (заголовок окна, серый) и справа `actions` плюс крестик «Закрыть».
4. Тело — `children`, прокручивается само, шапка и подвал на месте.
5. Подвал `footer` — кнопки делят ширину поровну, высота 44px.

## Состояния

- `open` — шторка показана; состояние держит страница.
- Закрытие — крестик, Escape, клик по подложке, смахивание вниз, кнопка «Назад» на Android. Все пути вызывают `onRequestClose`; вернуть `false` — шторка останется открытой (несохранённые правки). Закрыть по-настоящему — выставить `open` в `false`.
- `scrollKey` — при смене значения тело прокручивается наверх: другая задача в той же шторке.
- Открытый внутри [Select](#/c/Select) при клике мимо закрывает только себя, шторка остаётся.

## В киоске

Шторка рендерится в портал вне `.vs-kiosk`, поэтому класс киоска передают ей самой: `className="vs-kiosk"`. Тогда рамка и линия под шапкой пропадают, фон `--vs-surface-1`, скругление `--vs-radius-xl`, шапка крупнее, кнопки в шапке круглые на сером фоне, отступы тела больше.

## Доступность

- `head` становится заголовком диалога, скринридер читает его при открытии.
- Фокус уходит внутрь шторки и возвращается на кнопку, которая её открыла.
- У крестика подпись «Закрыть»; кнопки в `actions` — [IconButton](#/c/IconButton) с `label`.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `head` — что открыто: «T-121 · Review» | «Информация», «Детали» |
| Главное действие — `primary` в `footer` | Кнопки действий в конце длинного тела |
| `onRequestClose` возвращает `false` при несохранённых правках | Терять текст комментария по случайному касанию подложки |
| `className="vs-kiosk"` у шторки на стене | Оборачивать кнопку-открывашку в `.vs-kiosk` и ждать, что шторка подхватит |
| Ширину менять переменной `--vs-sheet-w` | Писать `.vs-sheet { width: … }` на сайте |
