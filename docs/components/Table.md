# Table

Таблица строк с одинаковыми колонками, когда значения сравнивают между собой: цены товаров, расходы по категориям, задачи доски, сервисы с портами.

## Когда применять

- У каждой строки 3 и больше одинаковых полей, и их сравнивают по колонке: «Цена» у пяти товаров Ленты, «Сумма» по категориям расходов.
- Нужна колонка чисел, выровненная вправо: `numeric`.
- Строка открывает подробности: `onRowClick`.

## Когда не применять

- У строки одно название и одна-две детали — [List](#/c/List).
- Показатели одного объекта — [KeyValue](#/c/KeyValue).
- Стена в коридоре: таблица в киоске читается плохо, берите [List](#/c/List) с `meta`.
- Динамика во времени — графики из `@vshome/ui/charts`.

## Анатомия

1. Обёртка с горизонтальной прокруткой: широкая таблица не ломает страницу.
2. Шапка — 12 px полужирным серым.
3. Ячейки — 14 px, разделитель снизу, выравнивание по верху.
4. Колонка (`columns[]`): `key`, `label`, `render` для своего содержимого, `width`.

## Колонки

| Поле колонки | Когда |
|---|---|
| `numeric` | суммы, цены, проценты: вправо, моноширинные цифры |
| `nowrap` | даты, номера задач, короткие коды, которые нельзя переносить |
| `muted` | второстепенная колонка: источник, комментарий |
| `width` | фиксировать ширину узкой колонки: «Статус», «Порт» |
| `render` | своё содержимое: [Tag](#/c/Tag), [StatusDot](#/c/Legend), форматированная сумма |

Без `render` выводится `row[key]` строкой.

## Состояния

- `dense` — меньше отступы, для длинных таблиц в админке.
- Пустая: если задан `empty`, вместо таблицы выводится он; без `empty` остаётся шапка без строк.
- Строка с `onRowClick` подсвечивается при наведении, получает фокус и открывается по Enter и пробелу.

## В киоске

Текст и отступы умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`), своих правил нет.

## Доступность

- `caption` — настоящий `<caption>`, визуально скрытый; видимый заголовок ставьте над таблицей.
- Шапка размечена `th scope="col"`.
- Нажимаемая строка открывается по Enter и пробелу, роли кнопки у неё нет; если в строке одно действие, дайте его ещё и ссылкой или кнопкой в ячейке.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `numeric` для сумм и цен | Выравнивать числа пробелами |
| Форматировать в `render`: «48 230 ₽» | Сырые `48230.5` из API |
| `empty="Покупок пока нет"` | Шапка без строк и без объяснения |
| `rowKey` по id записи | `rowKey` по индексу у сортируемой таблицы |
| Менять вид через переменные дизайн-системы | Перебивать `.vs-table__cell` на сайте |
