# Snippet

Плотная карточка объекта в выдаче: картинка слева, название в две строки, мелкая служебная строка, цена, метки и действия. Вся карточка ведёт по `href`, а кнопки в углу и в ряду действий нажимаются отдельно. Товар в выдаче Ленты, позиция в каталоге, ссылка с превью.

## Когда применять

- Сетка однотипных объектов, где у каждого есть картинка, название, пара служебных фактов и одно-два действия: «Выгодно», «Акции», «Избранное» в Ленте.
- Карточка должна вести на страницу объекта целиком, но в ней есть свои кнопки: избранное, «в список», «не показывать».

## Когда не применять

- Строка в списке без картинки и действий — [ListRow](#/c/List).
- Свободный блок с произвольным содержимым — [Card](#/c/Card).
- Плитка киоска — [Tile](#/c/Tile).

## Анатомия

1. `media` — слева, обычно [Artwork](#/c/Artwork) `size="md"` или `lg`.
2. `title` — полужирный 16px, `titleLines` строки (по умолчанию 2) с многоточием. С `href` название становится ссылкой, которая растянута на всю карточку.
3. `meta` — служебные строки 12px серым: рейтинг, КБЖУ, остаток. Каждый дочерний элемент — своя строка.
4. `price` — ряд: [Price](#/c/Price) и главная метка рядом с ним.
5. `tags` — ряд [Tag](#/c/Tag) `size="sm"`.
6. `actions` — всегда одна строка, без переноса: [IconButton](#/c/IconButton) `size="sm" variant="ghost"` с `label` и одна короткая [Button](#/c/Button) `size="sm" variant="ghost"`. Что не влезает в строку, уходит в [ContextMenu](#/c/ContextMenu) или в иконку с подсказкой — это контракт компонента, длинный ряд будет обрезан.
7. `corner` — правый верхний угол, обычно [IconButton](#/c/IconButton) `size="sm" variant="ghost" pressed`.

## Варианты

| Проп | Когда |
|---|---|
| `tone="muted"` | объект неактивен: нет в наличии, скрыт |
| `elevated` | тень вместо рамки |
| `external` | `href` открывается в новой вкладке |
| `as` | `article` по умолчанию, `li` внутри списка |

## Состояния

- Наведение на карточку-ссылку — лёгкое затемнение всей карточки, только на устройствах с указателем.
- Фокус на ссылке — кольцо `--vs-focus-ring` вокруг всей карточки.
- Кнопки и ссылки внутри `meta`, `price`, `tags`, `actions` и `corner` лежат поверх растянутой ссылки: нажатие на них не открывает объект.

## Доступность

- Имя ссылки — текст `title`, поэтому название должно быть понятным само по себе.
- Карточка не вкладывает кнопки в ссылку: ссылка — только название, остальная площадь кликабельна через псевдоэлемент. Разметка валидна, скринридер читает кнопки отдельно.
- У кнопки в углу обязателен `label`: «В избранное», «Убрать из избранного».

## Делай / не делай

| Делай | Не делай |
|---|---|
| Служебное — в `meta` одной-двумя строками через « · » | Семь отдельных строк под названием |
| Главная метрика — в `price` рядом с ценником | Главную метку отдельной строкой внизу |
| Редкие действия — ghost `sm` в `actions` или в [ContextMenu](#/c/ContextMenu) | Красные подчёркнутые ссылки действий |
| Сетка — [Grid](#/c/Grid) `min="md"`; карточка не тянется по высоте ряда, а выравнивается по верху | Растягивать карточки ради ровного низа, оставляя пустоту между мета и действиями |
| Значение с единицей неразрывно: «НЖК ≈4,5 г» | Единица, перенесённая одна на следующую строку |
