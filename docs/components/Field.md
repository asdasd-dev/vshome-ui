# Field

Поле формы с подписью, подсказкой и ошибкой. `TextField` — однострочный ввод, `TextArea` — многострочный; оба собраны на `Field`. Сам `Field` нужен, когда внутрь надо поставить свой элемент ввода и получить ту же подпись, подсказку и связи для скринридера.

## Когда применять

- Ввод текста: название задачи на доске, заметка к встрече в «Столе», количество товара — `TextField`.
- Поиск по списку: товары в Ленте, задачи на доске — `TextField type="search"`, иконка лупы появляется сама.
- Длинный текст: описание задачи, комментарий к покупке — `TextArea`.
- Свой элемент ввода с подписью и ошибкой в общем стиле — `Field` с функцией-потомком, которая получает `id`, `className`, `aria-describedby` и `aria-invalid`. Передайте их элементу целиком (`<input {...p} />`), и поле будет выглядеть как `TextField`.

## Когда не применять

- Выбор из готового списка — [Select](#/c/Select).
- Число в диапазоне, которое удобнее тянуть, — [Slider](#/c/Slider).
- Да/нет — [Checkbox](#/c/Checkbox) или [Switch](#/c/Switch).

## Анатомия

1. Подпись `label` — мелкий серый текст над полем; `hideLabel` прячет её визуально, но оставляет скринридеру.
2. Поле — рамка `--vs-line`, фон `--vs-bg`, текст `md`; у поиска слева иконка `search`.
3. Подсказка `hint` — мелкий серый текст под полем.
4. Ошибка `error` — под подсказкой, цвет `--vs-danger`; рамка поля тоже красная.

## Варианты и размеры

| Проп | Значение | Когда |
|---|---|---|
| `variant` | `default` | обычное поле |
| `variant` | `dashed` | пунктирная рамка без фона: строка «добавить пункт» в конце списка покупок или задач |
| `size` | `md` | по умолчанию, высота 40 px × масштаб |
| `size` | `sm` | высота 32 px, текст `sm`: строки таблиц, фильтры в шапке |

`TextArea` по умолчанию в 3 строки (`rows`), тянется по высоте.

## Состояния

- Фокус — кольцо `--vs-focus-ring` вместо рамки.
- `error` — красная рамка, текст ошибки под полем, `aria-invalid`.
- `disabled` — прозрачность 50% у поля; подпись остаётся как есть.
- Загрузки нет: на время запроса выключайте поле и кнопку формы.

## В киоске

Отдельных переменных нет: высота и отступы заданы через `--vs-scale` и в `.vs-kiosk` растут в 1,25 раза.

## Доступность

- `label` обязателен и связан с полем через `htmlFor`: даже у поиска с `hideLabel` скринридер слышит «Поиск товаров».
- `hint` и `error` подключены к полю через `aria-describedby` и читаются после подписи.
- Остальные атрибуты `<input>` и `<textarea>` (`placeholder`, `autoComplete`, `inputMode`, `maxLength`) передаются как есть.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Подпись в `label`, пример в `placeholder` | Подпись только в `placeholder` |
| `error="Укажите название задачи"` | `error="Ошибка"` или красный текст рядом вручную |
| `type="search"` для поиска | Своя иконка лупы поверх поля |
| `inputMode="decimal"` для цены | `type="text"` и разбор чисел на сайте |
| Новый вид — `variant` или `size` в дизайн-системе | `.shop .vs-text-field { border-radius: 0 }` на сайте |
