# RangeSlider

Ползунок диапазона с двумя бегунками: «от» и «до» на одной шкале. Отправляет пару значений один раз, когда палец отпущен (`onCommit(lo, hi)`), а не на каждый шаг.

## Когда применять

- Фильтр по диапазону в Ленте: скидка от 20 до 50%, рейтинг от 4,0 ★.
- Границы, которые проще показать на шкале, чем ввести: цена за килограмм от и до.

## Когда не применять

- Одно значение (яркость, громкость, порог) — [Slider](#/c/Slider).
- Точные границы, которые вводят с клавиатуры: суммы с копейками — два [TextField](#/c/Field).
- Три–четыре готовых диапазона («до 100 ₽», «100–300 ₽») — [ChipGroup](#/c/Chip).

## Анатомия

1. Дорожка `--vs-surface-2` на всю ширину контейнера, высота строки 32px × масштаб.
2. Заливка между бегунками — цвет тона.
3. Два круглых бегунка с рамкой цвета тона.

Значений на шкале нет: подпись с выбранным диапазоном («Скидка 20–50%») сайт рисует сам над ползунком через [Text](#/c/Text). `format` влияет только на то, что слышит скринридер.

## Варианты

`tone` — цвет заливки и рамки бегунков из общего набора: `accent` (по умолчанию), `ok`, `warn`, `danger`, `muted`, `violet`, `pink`, `gold`. Для рейтинга — `gold`, как у звёзд.

## Состояния

- Перетаскивание — бегунок и заливка двигаются сразу, `onCommit(lo, hi)` вызывается при отпускании, если пара изменилась.
- Бегунки не перескакивают друг через друга: «от» упирается в «до» и наоборот.
- Новое `value` сверху сбрасывает положение бегунков.
- С клавиатуры — стрелки меняют значение на `step`, `onCommit` при отпускании клавиши.
- Фокус — кольцо `--vs-focus-ring` вокруг дорожки.
- `disabled` — прозрачность 50%, курсор «нельзя».

## В киоске

Высота и бегунки заданы через `--vs-scale` и в `.vs-kiosk` растут в 1,25 раза.

## Доступность

- `label` обязателен: он становится именем группы, а бегунки получают «Скидка: от» и «Скидка: до».
- Бегунки — два `<input type="range">` с `min`, `max`, `step`; `aria-valuetext` из `format`: скринридер читает «20%», «4,5 ★».

## Делай / не делай

| Делай | Не делай |
|---|---|
| Подпись с выбранным диапазоном над ползунком | Ползунок без видимых чисел |
| Запрос к API в `onCommit` | Фильтровать список на каждый шаг |
| `step={5}` для процентов скидки | Шаг 1 на шкале 0–1000 для пальца |
| `tone="gold"` для рейтинга | Свой цвет через CSS сайта |
