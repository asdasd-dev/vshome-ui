# Excerpt

Описание, обрезанное по высоте блока: если текст не помещается, низ гаснет, а по касанию весь текст открывается в шторке с заголовком. Сделан для плиток стены и «Стола», где высота задана сеткой.

## Когда применять

- Описание встречи в плитке «Следующая встреча»: повестка из календаря, ссылки, участники.
- Текст новости или заметки на стене, где под него осталось место между заголовком и кнопками.

## Когда не применять

- Обрезка по числу строк без шторки — `lines` у [Text](#/c/Text).
- Текст с разметкой, абзацами и ссылками — [Prose](#/c/Prose); Excerpt принимает только строку.
- Раскрытие на месте, без шторки — [Disclosure](#/c/Disclosure).
- Блок без ограничения высоты: там Excerpt просто покажет весь текст.

## Анатомия

1. Текст (`children`) — строка, 16 px серым, переносы строк из исходного текста сохраняются.
2. Затухание снизу — маска появляется, только если текст не влез.
3. Шторка [Sheet](#/c/Sheet): заголовок `title` ролью `display`, полный текст ролью `lead`.

## Раскладка

Excerpt занимает всё свободное место по высоте в колонке (`flex: 1 1 0`) и сам ничего не обрезает, если родитель растёт под содержимое. Ставьте его внутрь [Tile](#/c/Tile) или другого блока с заданной высотой, между заголовком и подвалом.

## Состояния

- Текст влез — обычный текст, не нажимается.
- Не влез — затухание, курсор-рука, касание или Enter/пробел открывают шторку.
- Размер блока меняется — проверка повторяется сама.

## В киоске

Текст и отступы умножаются на `--vs-scale` (1,25). Если Excerpt стоит внутри `.vs-kiosk`, шторка открывается тоже в виде киоска.

## Доступность

- Обрезанный текст становится кнопкой (`role="button"`, `tabIndex=0`) и открывается с клавиатуры.
- Заголовок шторки — `title`; передавайте то же название, что видно в плитке.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Excerpt внутри [Tile](#/c/Tile) с фиксированной высотой | В блоке, который растёт по содержимому |
| `title` — название встречи или новости | Пустой или общий `title`: «Подробнее» |
| Чистая строка без HTML | Передавать разметку строкой |
| Менять затухание и цвет в дизайн-системе | Перебивать `.vs-excerpt` на сайте |
