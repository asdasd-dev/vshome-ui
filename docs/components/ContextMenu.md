# ContextMenu

Меню по правому клику или долгому нажатию на элемент: действия над ним, флажки и выбор одного значения. Пункты задаются данными в `items`, оборачиваемый элемент — единственный ребёнок.

## Когда применять

- Второстепенные действия над карточкой задачи на доске: «Открыть карточку», «Скопировать T-133», сменить статус.
- Быстрые переключатели объекта без открытия формы: «Делает агент».
- Действия над постом в Ленте, которые не нужны на виду постоянно.

## Когда не применять

- Единственный способ сделать действие — меню никто не найдёт; нужна видимая [Button](#/c/Button).
- Форма с полями — [Sheet](#/c/Sheet).
- Выбор значения поля формы — [Select](#/c/Select).
- Вторая кнопка рядом с основной — [SplitButton](#/c/SplitButton).

## Анатомия

1. Цель — `children`, один элемент; меню вешает на него свои обработчики.
2. Всплывающая панель — фон `--vs-panel`, тень `--vs-shadow-popover`, прокрутка без полосы, если не помещается.
3. Пункт-действие `{ label, onSelect }`.
4. Флажок `{ label, checked, onCheckedChange }` — галочка в левой колонке.
5. Группа выбора `{ label, value, options, onValueChange }` — серая подпись группы и пункты с галочкой у текущего.
6. Разделитель — строка `"separator"`.

## Состояния

- Подсветка пункта — фон `--vs-accent-tint` при наведении и стрелках.
- `disabled` у пункта или варианта — прозрачность 50%, не выбирается.
- `disabled` у меню — меню не открывается, браузерное меню тоже не появится.
- `longPress` (по умолчанию `true`) — открывать долгим нажатием пальца. `longPress={false}` — меню только по правому клику мышью, касания целиком остаются странице (перетаскивание карточек на доске).
- На сенсорных экранах пункты выше: 44px вместо 36px.

## Доступность

- Открывается клавишей контекстного меню и Shift+F10, пункты — стрелками, выбор — Enter, закрытие — Escape.
- Флажки и выбор одного отдаются как `menuitemcheckbox` и `menuitemradio`, скринридер слышит состояние.
- Всё, что есть в меню, должно быть доступно и другим путём: меню скрыто, его не видно без подсказки.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Ребёнок — элемент, который принимает пропсы: `div`, `button` | Компонент без проброса пропсов (`Card` напрямую): обработчики потеряются |
| Глагол в пункте: «Скопировать T-133» | «Копирование» |
| Опасное действие — внизу, после разделителя | «Удалить» первым пунктом |
| `longPress={false}`, если касание занято перетаскиванием | Ловить `touchstart` на цели самому |
| Вид менять через токены дизайн-системы | Писать `.vs-menu__item { … }` на сайте |
