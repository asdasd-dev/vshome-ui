# Stat

Крупное число с единицей и подписью — главное содержание плитки: сколько минут до встречи, сколько потрачено за месяц, сколько стоит товар.

## Когда применять

- Одна цифра, ради которой открывают блок: «12 мин» до синка, «48 230 ₽» расходов, «89,99 ₽» за молоко.
- Время следующего события: «14:00» с подписью «через 40 мин».
- Цифра с иконкой: температура с погодой, число агентов с иконкой статуса.

## Когда не применять

- Несколько равноправных пар «название — значение» — [KeyValue](#/c/KeyValue).
- Число как доля от целого — [Progress](#/c/Progress) рядом со Stat или вместо.
- Счётчик нового рядом с подписью — [Badge](#/c/Badge).
- Число внутри предложения — [Text](#/c/Text).

## Анатомия

1. Значение (`value`) — шрифт заголовков, моноширинные цифры.
2. Единица (`unit`) — серым, на одной базовой линии со значением: «мин», «₽», «мин осталось».
3. Иконка (`icon`) — справа от числа, по центру строки; `icon.label` обязателен.
4. Подпись (`caption`) — 14 px серым под числом: название встречи, период, источник.

## Размеры

| Размер | Значение | Когда |
|---|---|---|
| `md` | 32 | цифра второго плана: следующая встреча, ряд из 3–4 цифр |
| `lg` (по умолчанию) | 48 | главная цифра плитки |
| `xl` | 72 | одна цифра, которую видно через комнату: минуты до встречи на стене |

## Тоны

Тон красит только значение; единица и подпись остаются серыми.

- `default` — обычная цифра.
- `muted` — справочная или прошедшая: следующая встреча не скоро.
- `ok` — в норме: расходы в пределах бюджета.
- `warn` — скоро или близко к пределу: встреча через 3 мин.
- `danger` — сбой или перебор: встреча идёт без тебя, бюджет превышен.

## В киоске

Все размеры умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`). `xl` в киоске — 90 px; рядом с ним не ставьте вторую цифру того же размера.

## Доступность

- Значение и единица читаются подряд: «12 мин». Не прячьте единицу в иконку.
- Иконка без слова передаёт смысл только через `icon.label`: «ясно», «дождь».
- Цвет тона дублируйте подписью: «идёт без тебя», а не только красная цифра.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `value={12} unit="мин"` | `value="12 мин"` одной строкой |
| Одна `xl` на плитку | Две `xl` рядом |
| Форматировать число до передачи: «48 230» | «48230.5» из ответа API |
| Тон `warn`/`danger` с подписью-причиной | Красная цифра без объяснения |
| Менять размеры через `--vs-text-*` в дизайн-системе | Перебивать `.vs-stat__value` на сайте |
