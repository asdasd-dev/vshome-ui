# Artwork

Квадратная картинка со скруглением: обложка трека, аватар источника. Если картинки нет или она не загрузилась, показывает заглушку.

## Когда применять

- Обложка трека в плитке «Музыка» на стене и на «Столе».
- Картинка источника рядом с постом в Ленте.
- Любая квадратная миниатюра, у которой может не быть картинки.

## Когда не применять

- Значок интерфейса — [Icon](#/c/Icon).
- Картинка внутри статьи — `img` в [Prose](#/c/Prose).
- Иллюстрация пустого состояния — [EmptyState](#/c/EmptyState).

## Анатомия

1. `img` квадратом, `object-fit: cover`, скругление `--vs-radius-md`.
2. Заглушка `fallback` — серый квадрат `--vs-surface-2` с содержимым по центру: символ, [Icon](#/c/Icon), инициалы.

## Размеры

| `size` | Ширина | Когда |
|---|---|---|
| `sm` | 44px | строка списка |
| `md` (по умолчанию) | 56px | пост в Ленте, компактная плитка |
| `lg` | 96px | плитка «Музыка» |

## Состояния

- Нет `src` — сразу заглушка.
- Ошибка загрузки — заглушка вместо битой картинки. Новый `src` пробуется снова.

## В киоске

Размеры растут на `--vs-scale` вместе со всем внутри `.vs-kiosk`: `lg` на стене — 120px.

## Доступность

- `alt` пустой по умолчанию: картинка декоративная, если название трека написано рядом.
- Если рядом текста нет, передайте `alt` — его получит и картинка, и заглушка (`role="img"`).

## Делай / не делай

| Делай | Не делай |
|---|---|
| Всегда задавать `fallback`: «♪», иконку, инициалы | Оставлять пустой серый квадрат |
| Название трека рядом через [Text](#/c/Text) `lines={1}` | Писать название поверх картинки |
| Размер через `size` | Задавать `width` своим CSS |
| `alt=""`, если подпись рядом | Дублировать название трека в `alt` |
