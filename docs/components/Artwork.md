# Artwork

Квадратная картинка со скруглением: обложка трека, аватар источника, фото товара. Если картинки нет или она не загрузилась, показывает заглушку.

## Когда применять

- Обложка трека в плитке «Музыка» на стене и на «Столе».
- Картинка источника рядом с постом в Ленте.
- Фото товара в карточке Ленты: `size="fill"` на ширину карточки, `fit="contain"` с `backdrop`.
- Любая квадратная миниатюра, у которой может не быть картинки.

## Когда не применять

- Значок интерфейса — [Icon](#/c/Icon).
- Картинка внутри статьи — `img` в [Prose](#/c/Prose).
- Иллюстрация пустого состояния — [EmptyState](#/c/EmptyState).

## Анатомия

1. `img` квадратом, скругление `--vs-radius-md`; `fit` — как картинка ложится в квадрат.
2. Заглушка `fallback` — серый квадрат `--vs-surface-2` с содержимым по центру: символ, [Icon](#/c/Icon), инициалы.

## Размеры

| `size` | Ширина | Когда |
|---|---|---|
| `sm` | 44px | строка списка |
| `md` (по умолчанию) | 56px | пост в Ленте, компактная плитка |
| `lg` | 96px | плитка «Музыка» |
| `fill` | 100% ширины контейнера | фото товара в карточке, сетка [Grid](#/c/Grid) |

Квадрат сохраняется при любом размере: `fill` в карточке шириной 240px даёт картинку 240 × 240.

## Вписывание и фон

- `fit="cover"` (по умолчанию) — картинка заполняет квадрат, края обрезаются: обложки, аватары.
- `fit="contain"` — картинка целиком, по бокам поля: фото товаров, где обрезать упаковку нельзя.
- `backdrop` — фон под картинкой и заглушкой из общего набора тонов (`accent`, `ok`, `warn`, `danger`, `muted`, `violet`, `pink`, `gold`), мягкий оттенок `--vs-*-soft`. С `contain` закрашивает поля вокруг товара: прозрачные PNG не висят на фоне карточки.

## Состояния

- Нет `src` — сразу заглушка.
- Ошибка загрузки — заглушка вместо битой картинки. Новый `src` пробуется снова.
- `loading` — `lazy` (по умолчанию): картинка грузится, когда подходит к экрану; длинная сетка товаров не качает всё сразу. `eager` — для картинки первого экрана: обложка трека на стене, фото на странице товара.

## В киоске

Размеры растут на `--vs-scale` вместе со всем внутри `.vs-kiosk`: `lg` на стене — 120px.

## Доступность

- `alt` пустой по умолчанию: картинка декоративная, если название трека написано рядом.
- Если рядом текста нет, передайте `alt` — его получит и картинка, и заглушка (`role="img"`).

## Делай / не делай

| Делай | Не делай |
|---|---|
| Всегда задавать `fallback`: «♪», иконку, инициалы | Оставлять пустой серый квадрат |
| Название трека рядом через [Text](#/c/Text) `lines={1}` | Писать название поверх картинки |
| Размер через `size`, на ширину карточки — `size="fill"` | Задавать `width` своим CSS |
| `fit="contain"` для упаковок товаров | Обрезать этикетку через `cover` |
| `alt=""`, если подпись рядом | Дублировать название трека в `alt` |
