# Spinner

Вращающееся кольцо: идёт загрузка, и доля готовности неизвестна. Цвет берёт от текста вокруг.

## Когда применять

- Первая загрузка блока, пока данных нет: плитка новостей, список агентов.
- Короткое ожидание рядом с текстом: «Обновляю цены…».

## Когда не применять

- Загрузка после нажатия кнопки — `loading` у [Button](#/c/Button), он ставит спиннер в кнопку сам.
- Известна доля: загружено 30 из 42 товаров — [Progress](#/c/Progress).
- Данные уже есть и обновляются в фоне — оставьте старые и покажите «Данные за 10 мин назад» [Banner](#/c/Banner), а не спиннер поверх.
- Данных нет и не будет — [EmptyState](#/c/EmptyState).

## Анатомия

Кольцо толщиной 2 px цвета `currentColor` с прозрачной четвертью, один оборот за `--vs-duration-spin`.

## Размеры

| Размер | Диаметр | Когда |
|---|---|---|
| `sm` | 16 | в строке текста, в кнопке, в строке списка |
| `md` (по умолчанию) | 20 | в заголовке блока, рядом с подписью |
| `lg` | 32 | по центру пустой плитки или страницы при первой загрузке |

## Цвет

По умолчанию кольцо красится в цвет текста родителя. `tone` — общий набор тонов (`accent`, `ok`, `warn`, `danger`, `muted`, `violet`, `pink`, `gold`): `tone="muted"` для фоновой загрузки, `tone="accent"` на пустой странице.

## Состояния

При `prefers-reduced-motion` кольцо вращается в 3 раза медленнее, но не останавливается: иначе не видно, что идёт работа.

## В киоске

Диаметр умножается на `--vs-scale` (1,25 внутри `.vs-kiosk`), своих правил нет.

## Доступность

- С `label` — `role="status"` с этим именем: «Загружаю новости».
- Без `label` скрыт от скринридера; так нужно, если рядом уже есть текст «Обновляю цены…».

## Делай / не делай

| Делай | Не делай |
|---|---|
| `label="Загружаю агентов"` или текст рядом | Голый спиннер без объяснения на пустой странице |
| `loading` у кнопки | Спиннер рядом с кнопкой вручную |
| Старые данные + «обновлено N мин назад» | Спиннер поверх данных при каждом опросе |
| Цвет через `tone` или цвет родительского текста | Красить `.vs-spinner` своим `border-color` на сайте |
