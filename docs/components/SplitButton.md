# SplitButton

Кнопка из двух частей в одной капсуле: слева основное действие (включить свет, запустить сцену), справа стрелка, открывающая подробности или настройки. Основное действие может держать состояние (`pressed`) и иметь второе действие по долгому нажатию (`onHold`).

## Когда применять

- Переключатель на стене, у которого есть экран настроек: «Свет в коридоре» + яркость, «Ночной» + состав сцены.
- Действие с быстрым вариантом по удержанию: короткое нажатие — «Ворота» открыть, удержание — открыть калитку.
- Кнопка в «Столе», у которой есть подробности: «Встреча» запускает таймер, стрелка открывает карточку встречи.

## Когда не применять

- Второго действия нет — [Button](#/c/Button).
- Справа нужен список из нескольких действий — [Button](#/c/Button) и [ContextMenu](#/c/ContextMenu).
- Только вкл/выкл без подписи-действия — [Switch](#/c/Switch) в строке [ControlList](#/c/ControlList).
- Выбор одного режима из нескольких — [Segment](#/c/Segment).

## Анатомия

1. Капсула — фон `--vs-split-bg` (`--vs-surface-2`), у нажатой — `--vs-split-pressed` (`--vs-accent-soft`).
2. Основная часть (`children`, `onClick`) — иконка `icon` и подпись, одна строка.
3. Лампа (`indicator="lamp"`) — жёлтая точка в левом отступе у нажатой кнопки; фон при этом не меняется.
4. Разделитель — тонкая вертикальная черта.
5. Правая часть (`more`) — иконка `more.icon` (по умолчанию `chevron-right`), подпись `more.label` уходит в `aria-label` и подсказку.

## Состояния

- Наведение — затемнение той половины, над которой указатель.
- Фокус — кольцо внутри каждой половины отдельно.
- `pressed` — фон `--vs-accent-soft` у всей капсулы, `aria-pressed` на основной части; с `indicator="lamp"` вместо фона — точка.
- Удержание — если задан `onHold`, через `holdMs` (по умолчанию 500 мс) вызывается он, и следующий `onClick` не срабатывает. Системное меню по долгому касанию при этом отключено.
- `disabled` — выключает обе части: прозрачность 50%, курсор «нельзя».

## В киоске

Внутри `.vs-kiosk` высота 44 × масштаб, текст `md` и вес `medium`, отступы обеих частей шире. Всё задаётся переменными `--vs-split-*` на `.vs-kiosk`; на сайте ничего не меняйте.

## Доступность

- Это две кнопки: скринридер слышит подпись основной и `more.label` второй («Настройки света», а не «Ещё»).
- Правая часть отдаётся с `aria-haspopup="dialog"` — открывайте ею [Sheet](#/c/Sheet) или страницу настроек.
- `onHold` недоступен с клавиатуры: действие по удержанию должно быть и в том, что открывает `more`.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `more.label="Настройки света"` | `more.label="Ещё"` или «>» |
| `indicator="lamp"` у ряда сцен, где важно видеть, что горит | Лампа и закрашенный фон вперемешку в одном ряду |
| Дублировать действие `onHold` в шторке настроек | Прятать действие только за удержанием |
| Менять отступы и цвета через `--vs-split-*` в дизайн-системе | `.wall .vs-split__more { … }` на сайте |
