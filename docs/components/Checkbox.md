# Checkbox

`Checkbox` — флажок с подписью: отметить пункт или включить параметр формы. `RadioGroup` — группа круглых переключателей с заголовком, выбран ровно один вариант. Оба поддерживают пояснение `hint` под подписью.

## Когда применять

- Отметка пункта: «куплено» в списке покупок Ленты, «готово» в чек-листе задачи — `Checkbox` размера `lg` для пальца.
- Параметр формы, который применится после «Сохранить»: «Присылать сводку в Mattermost» при создании правила.
- Выбор одного варианта с пояснениями: «Когда напомнить» — «За 15 минут до встречи / За час / Утром в день встречи» — `RadioGroup`.

## Когда не применять

- Настройка применяется сразу, без «Сохранить» — [Switch](#/c/Switch).
- Два–четыре коротких режима без пояснений — [Segment](#/c/Segment).
- Длинный список вариантов — [Select](#/c/Select).
- Фильтр списка — [Chip](#/c/Chip).

## Анатомия

Checkbox:
1. Квадрат с рамкой `--vs-line`; у отмеченного заливка `--vs-accent` и галочка `--vs-on-accent`.
2. Подпись `label` — любой узел.
3. Пояснение `hint` — мелкий серый текст под подписью.

RadioGroup:
1. Заголовок `legend` — мелкий серый текст над вариантами; `hideLegend` прячет его визуально, но оставляет скринридеру.
2. Варианты — круг и подпись `label` с необязательным `hint`.

## Размеры и раскладка

- `Checkbox size="md"` — квадрат 20 px, по умолчанию.
- `Checkbox size="lg"` — 28 px, для списков, которые отмечают пальцем на ходу.
- `RadioGroup size="md"` — круг 20 px, по умолчанию; `size="lg"` — 28 px, в пару к `Checkbox size="lg"`.
- `RadioGroup direction="column"` — столбиком, по умолчанию; `direction="row"` — в строку с переносом, для двух–трёх коротких вариантов.

## Состояния

- Фокус — кольцо `--vs-focus-ring` вокруг квадрата или круга.
- Отмечен — заливка `--vs-accent`; у радио внутри остаётся кольцо фона.
- `disabled` у `Checkbox`, у всей `RadioGroup` или у отдельного варианта (`options[].disabled`) — бледнеет вся строка с подписью, курсор «нельзя»; причину объясните в `hint`.
- Промежуточного состояния («отмечено частично») нет.

## В киоске

Отдельных переменных нет: размеры заданы через `--vs-scale` и в `.vs-kiosk` растут в 1,25 раза. Квадрат `md` при этом — 25 px, `lg` — 35 px.

## Доступность

- Вся строка — `<label>`: нажатие на подпись тоже переключает.
- `RadioGroup` — `<fieldset>` с `<legend>`: скринридер называет группу перед вариантами. `legend` обязателен даже при `hideLegend`.
- Стрелки внутри `RadioGroup` переключают варианты.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `lg` в списке покупок | `md` в списке, который отмечают на ходу |
| Подпись — утверждение: «Присылать сводку» | Отрицание: «Не присылать сводку» |
| `hint` с причиной у выключенного варианта | Выключенный вариант без объяснения |
| `RadioGroup` с выбранным вариантом по умолчанию | Группа, где ничего не выбрано |
| Размер — через `--vs-checkbox-size` и токены в дизайн-системе | `.list .vs-checkbox__input { … }` на сайте |
