# ButtonGroup

Несколько однотипных действий под одной подписью в одной капсуле: «Калитка 1 · 2 · 5». Подпись слева, справа круглые кнопки с коротким текстом или иконкой.

## Когда применять

- Одно действие для нескольких похожих объектов: открыть калитку 1, 2 или 5.
- Места мало, а отдельные [Button](#/c/Button) с повтором подписи («Калитка 1», «Калитка 2») не помещаются в строку.

## Когда не применять

- Выбор одного варианта, который остаётся выбранным, — [Segment](#/c/Segment).
- Действия разные по смыслу — отдельные [Button](#/c/Button).
- У действия есть экран подробностей — [SplitButton](#/c/SplitButton).

## Анатомия

1. Капсула — фон `--vs-surface-2`, высота как у кнопки.
2. Подпись `label` — слева, общая для всех кнопок; для скринридера она имя группы.
3. Кнопки `items` — круглые, фон `--vs-surface-0`, текст `label` короткий (цифра) или [Icon](#/c/Icon) `sm`.

## Состояния

- Наведение и фокус — у каждой кнопки отдельно.
- `disabled` у элемента — прозрачность 50%, нажатие не вызывает `onClick`.

## В киоске

Внутри `.vs-kiosk` высота 44 × масштаб, текст `md` и вес `medium`, как у [SplitButton](#/c/SplitButton). Задаётся переменными `--vs-button-group-*`.

## Доступность

- Группа — `role="group"` с именем из `label`.
- У каждой кнопки `ariaLabel` с полным именем («Калитка 2»), а не только цифрой; он же уходит в подсказку.

## Делай / не делай

- Делай: 2–4 кнопки с однозначным коротким текстом.
- Не делай: длинные подписи внутри кнопок — круг под них не растёт.
