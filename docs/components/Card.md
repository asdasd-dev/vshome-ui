# Card

Поверхность для обычных сайтов: карточка задачи на доске, пост в Ленте, плитка сервиса на дашборде vshome.space. Умеет тон, цветную полосу слева, тень и клик целиком. Для стены и «Стола» нужна [Tile](#/c/Tile).

## Когда применять

- Отдельный объект в списке или сетке: задача, пост, сервис, репозиторий.
- Блок, который открывается целиком по клику (`onClick`) или ведёт по адресу (`href`).
- Блок с состоянием, которое видно по фону: `tone="danger"` у упавшего сервиса, `tone="muted"` у закрытой задачи.
- Принадлежность к группе цветом: `stripe` по репозиторию или домену.

## Когда не применять

- Блок киоска с подписью капсом и прокруткой — [Tile](#/c/Tile).
- Сообщение об ошибке или предупреждение на всю ширину — [Banner](#/c/Banner).
- Строка в списке — [ListRow](#/c/List): карточка на каждую строку даёт лишние рамки.
- Группа настроек — [ControlList](#/c/ControlList).
- Просто отступы и рамка вокруг куска раскладки — [Stack](#/c/Layout) без поверхности.

## Анатомия

1. Контейнер — рамка `--vs-line`, скругление `--vs-radius-lg`, фон `--vs-surface-1` или фон тона.
2. Полоса `stripe` — 4px слева.
3. Содержимое — что угодно; отступ задаёт `padding`.

## Варианты

| `tone` | Когда |
|---|---|
| `default` | обычная карточка |
| `accent` | выбранная или текущая |
| `ok` | всё хорошо, завершено успешно |
| `warn` | ждёт действия |
| `danger` | ошибка, сломано |
| `muted` | неактивная, закрытая, второстепенная |
| `violet`, `pink`, `gold` | категория без статусного смысла: домен задачи, раздел Ленты |

У цветных тонов рамка исчезает, остаётся фон.

`stripe` принимает имя тона (`accent`, `ok`, `warn`, `danger`, `muted`, `violet`, `pink`, `gold`) или любой цвет CSS (`#199e70`).

## Размеры и форма

- `padding`: `none` (картинка во всю карточку), `sm` (плотные списки), `md` по умолчанию, `lg` (крупные блоки дашборда).
- `elevated` — тень вместо рамки, для карточки, которая лежит поверх фона-картинки или выделяется над соседями.
- `as` — тег без клика: `section`, `article` (пост в Ленте), `li` (карточка внутри `ul`).

## Состояния

- С `onClick` карточка становится `button`, с `href` — ссылкой `a`; ширина 100%, курсор-рука, наведение затемняет, фокус — кольцо `--vs-focus-ring`. `as` в этом случае не действует.
- Внутри кликабельной карточки только строчные элементы: `Stack as="span"`, [Text](#/c/Text). Блочный `div` внутри `button` — невалидная разметка.

## Доступность

- `title` уходит в атрибут `title` — подсказка при наведении, не замена видимому тексту.
- У кликабельной карточки весь текст становится именем кнопки или ссылки: держите его коротким, без вложенных кнопок.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Одна карточка — один объект | Карточка внутри карточки |
| `href` для перехода, `onClick` для действия на месте | `onClick` с `location.href = …` |
| `Stack as="span"` внутри кликабельной карточки | Кнопки и ссылки внутри кликабельной карточки |
| Цвет группы через `stripe` | Красить фон карточки своим `style` |
| Перебивать вид через переменные дизайн-системы | Писать `.board .vs-card { border: … }` на сайте |
