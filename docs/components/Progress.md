# Progress

Полоса заполнения: `Progress` показывает одну долю от целого, `SplitBar` — как целое делится на части.

## Когда применять

- `Progress` — сколько потрачено из бюджета, сколько дел сделано, сколько трафика VPN израсходовано из лимита, сколько прошло от встречи.
- `SplitBar` — из чего состоят расходы месяца (еда, подписки, транспорт), сколько задач доски в inbox, doing и review.

## Когда не применять

- Ожидание без известной доли — [Spinner](#/c/Spinner).
- Точное число важнее доли — [Stat](#/c/Stat), полоса может стоять под ним.
- Динамика по дням или сравнение многих частей — графики из `@vshome/ui/charts`.
- Выбор значения пользователем — [Slider](#/c/Slider).

## Анатомия

1. Дорожка — капсула фона `--vs-surface-2`.
2. Заливка `Progress` — ширина `value / max`, цвет тона; значение за пределами `0…max` обрезается.
3. Части `SplitBar` — ширина пропорциональна `value`, между частями зазор; части с нулём не рисуются.

## Тоны

Общий набор тонов: `accent` (по умолчанию), `ok`, `warn`, `danger`, `muted`, `violet`, `pink`, `gold` — тот же, что у [Legend](#/c/Legend). Для `SplitBar` тон задаётся у каждой части; для цветов вне набора — `color` части.

| Тон | Когда |
|---|---|
| `accent` | нейтральный ход: сделано дел, прошло времени |
| `ok` | в пределах нормы: бюджет потрачен на 60% |
| `warn` | близко к пределу: 90% лимита |
| `danger` | предел превышен или сбой |
| `muted` | остаток, неучтённое |
| `violet`, `pink`, `gold` | части `SplitBar` без статусного смысла: категории расходов |

## Размеры

- `md` (по умолчанию) — 8 px, отдельная полоса в карточке.
- `sm` — 4 px, под цифрой [Stat](#/c/Stat) или в строке списка.

## Состояния

- Изменение `value` анимируется по ширине; при `prefers-reduced-motion` без анимации.
- `max={0}` — пустая полоса.

## В киоске

Высота умножается на `--vs-scale` (1,25 внутри `.vs-kiosk`), своих правил нет.

## Доступность

- `label` обязателен: `Progress` — `role="progressbar"` с этим именем и `aria-valuenow`/`aria-valuemax`.
- `SplitBar` — `role="img"`, скринридер читает `label` и ненулевые части с числами: «Расходы: Еда 31400, Подписки 4980».
- Подпись части видна подсказкой при наведении; на телефоне подсказок нет — ставьте [Legend](#/c/Legend) рядом.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `value={31400} max={35000}` | Считать проценты на сайте и передавать `max={100}` без нужды |
| Тон по смыслу доли: `warn` от 90% | Красная полоса при 20% бюджета |
| [Legend](#/c/Legend) с теми же тонами рядом со `SplitBar` | Части без подписи на телефоне |
| Цифру рядом с полосой | Только полоса там, где важно точное число |
| Менять высоту и цвета через переменные дизайн-системы | Перебивать `.vs-progress__fill` на сайте |
