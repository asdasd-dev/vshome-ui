# Disclosure

Сворачиваемый блок: строка-заголовок со стрелкой и содержимое под ней. Сделан на нативном `details`/`summary`, работает без JavaScript.

## Когда применять

- Подробности, которые нужны редко: текст ошибки деплоя, параметры выхода VPN.
- Длинный хвост списка: «Закрытые задачи · 12», «Показать ещё 5 постов».
- Второстепенные поля формы в [Sheet](#/c/Sheet).

## Когда не применять

- Переключение между равноправными разделами — [Tabs](#/c/Tabs).
- Содержимое, без которого страница непонятна, — показывать сразу.
- Подробности объекта с действиями — [Sheet](#/c/Sheet).
- Скрытые действия над объектом — [ContextMenu](#/c/ContextMenu).

## Анатомия

1. Заголовок `summary` — стрелка `chevron-right` и текст, вес medium.
2. Стрелка поворачивается вниз, когда блок раскрыт.
3. Тело `children` — отступ сверху `--vs-space-2`, без рамок и фона.

## Варианты

| `tone` | Когда |
|---|---|
| `default` | обычный заголовок основным цветом |
| `muted` | второстепенный хвост: «Показать ещё», архив |

## Состояния

- Свёрнут — по умолчанию.
- `open` — раскрыт при первом показе. Дальше блок открывается и закрывается сам, по клику; `open` задаёт начальное состояние, а не держит его.
- `onToggle` — сообщает новое состояние (`true` — раскрыт), например чтобы запомнить его.
- Фокус — кольцо `--vs-focus-ring` на заголовке.

## Доступность

- Заголовок — нативный `summary`: доступен с клавиатуры (Enter, пробел), скринридер слышит «свёрнуто» или «развёрнуто».
- Текст заголовка говорит, что внутри, и по возможности сколько: «Закрытые задачи · 12».

## Делай / не делай

| Делай | Не делай |
|---|---|
| «Подробности ошибки», «Закрытые задачи · 12» | «Ещё», «Развернуть» без предмета |
| `tone="muted"` для хвостов и архива | Прятать главное содержимое страницы |
| Один уровень сворачивания | `Disclosure` внутри `Disclosure` внутри `Disclosure` |
| Вид менять через токены дизайн-системы | Возвращать стандартный треугольник своим CSS |
