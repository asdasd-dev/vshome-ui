# Slider

Широкая полоса-ползунок для числа в диапазоне: тянешь пальцем, заливка показывает уровень, значение подписано справа внутри полосы. Отправляет значение один раз, когда палец отпущен (`onCommit`), а не на каждый шаг.

## Когда применять

- Уровень устройства на стене и в шторке: яркость света, громкость колонки, температура на термостате.
- Числовая настройка, где важен порядок величины, а не точное число: «Порог уведомления о цене, %» в Ленте.

## Когда не применять

- Нужно ввести точное число (цену, количество) — [TextField](#/c/Field) с `type="number"`.
- Три–четыре фиксированных уровня («Тихо / Средне / Громко») — [Segment](#/c/Segment).
- Вкл/выкл — [Switch](#/c/Switch).
- Показать уровень без изменения — [Progress](#/c/Progress).

## Анатомия

1. Полоса-капсула высотой 44 px × масштаб, на всю ширину контейнера.
2. Заливка `--vs-accent-fill` от начала до текущего значения.
3. Значение справа — результат `format`, по умолчанию просто число.

Ручки нет: тянуть можно за любое место полосы.

## Состояния

- Касание — вертикальный свайп с полосы прокручивает страницу и значение не трогает; тянет только движение вдоль полосы больше 8 px. Тап без движения ставит значение под пальцем. Мышь — сразу по нажатию. Жест общий у `Slider`, `Seek` и `RangeSlider` (`useRangeGesture`), нативный `input` касание не ловит.
- Перетаскивание — значение и заливка меняются сразу, `onCommit` вызывается при отпускании, если значение изменилось.
- Пока палец на полосе, новые `value` сверху не сбивают положение; после отпускания полоса принимает внешнее `value`.
- С клавиатуры — стрелки меняют значение на `step`, `onCommit` при отпускании клавиши.
- Фокус — кольцо внутри полосы.
- `disabled` — прозрачность 50%, курсор «нельзя»: устройство не в сети.

## В киоске

Отдельных переменных нет: высота и отступ подписи заданы через `--vs-scale` и в `.vs-kiosk` растут в 1,25 раза.

## Доступность

- `label` обязателен и уходит в `aria-label`: «Яркость света в коридоре».
- Это `<input type="range">` с `min`, `max`, `step`; `aria-valuetext` берётся из `format`, скринридер читает «70%», а не «70».
- По умолчанию `min` равен 1, а не 0. Для шкал от нуля задавайте `min={0}` явно.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `` format={(v) => `${v}%`} `` для процентов | Отдельный текст со значением рядом с полосой |
| Отправлять запрос в `onCommit` | Пытаться слать запрос на каждый шаг перетаскивания |
| `step={0.5}` для термостата | Шкала 0–1000 с шагом 1 для пальца |
| Высоту и цвета — через токены в дизайн-системе | `.wall .vs-slider { height: 60px }` на сайте |

## Новое в 0.39

- `icon` — иконка слева внутри полосы: `icon="volume"` для громкости. Декоративная, имя полосы по-прежнему из `label`.

## Новое в 0.42

- `variant="line"` — тонкая полоса с круглой ручкой, как у [Seek](#/c/Seek), с иконкой слева и без подписи значения (оно остаётся в `aria-valuetext`). Для второстепенной настройки рядом с главным, например громкость в плитке «Музыка». По умолчанию `bar` — прежняя широкая капсула.

## Новое в 0.45

- `orientation="vertical"` у `variant="line"` — вертикальная тонкая полоса, растёт снизу вверх, иконка под ней. Высоту задаёт контейнер. Для громкости, которая выезжает по кнопке и не занимает место в плитке.

## Новое в 0.46

- `elevated` у `variant="line"` — полоса в приподнятой капсуле (`--vs-panel`, тень `--vs-shadow-popover`): для полосы, которая выезжает поверх содержимого, например громкость по кнопке в плитке «Музыка».

## Новое в 0.47

- `elevated` лежит слоем `--vs-z-raised` над соседним содержимым: раскрытая поверх плитки полоса не уходит под позиционированные элементы (полосу перемотки).
