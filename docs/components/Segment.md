# Segment

Сегментированный переключатель: два–четыре взаимоисключающих варианта в одной рамке, выбран всегда ровно один. Меняет вид или режим того, что ниже, а не фильтрует список.

## Когда применять

- Период графика на дашборде vshome.space: «День / Неделя / Месяц».
- Вид списка: «Карточки / Таблица» на доске задач.
- Режим на стене: «Дом / Двор» над плитками комнат.

## Когда не применять

- Вариантов больше четырёх или подписи длинные — [Select](#/c/Select) или [ChipGroup](#/c/Chip) со `scroll`.
- Фильтр со счётчиками — [ChipGroup](#/c/Chip).
- Вкл/выкл одного параметра — [Switch](#/c/Switch).
- Переключение разделов страницы со своим содержимым — [Tabs](#/c/Tabs).
- Выбор в форме с подписями-пояснениями — [RadioGroup](#/c/Checkbox).

## Анатомия

1. Рамка-подложка `--vs-surface-1` с границей `--vs-line`.
2. Сегменты — кнопки с подписью `label` опции; в подписи можно иконку.
3. Выбранный сегмент — заливка.

## Варианты

| `variant` | Вид | Когда |
|---|---|---|
| `default` | рамка, выбранный — тёмная заливка `--vs-ink` | обычные страницы, шапки графиков |
| `soft` | капсула без рамки, выбранный — `--vs-surface-2` | спокойные места: стена, шапка «Стола», поверх карточек |

## Размеры

- `md` — по умолчанию.
- `sm` — мельче текст и отступы: шапка графика в карточке, плотная панель.

## Состояния

- Наведение — затемнение невыбранного сегмента, только на устройствах с указателем.
- Фокус — кольцо внутри сегмента.
- Выбранный — `aria-pressed="true"`.
- `disabled` у опции — прозрачность 50%, курсор «нельзя», сегмент не нажимается: «Месяц», пока нет данных за месяц.

## В киоске

Внутри `.vs-kiosk` текст сегментов `md` через `--vs-segment-size` и `--vs-segment-leading`, отступы растут с `--vs-scale`. На сайте ничего не меняйте.

## Доступность

- `label` обязателен и уходит в `aria-label` группы: «Период графика», «Вид списка». Старый `ariaLabel` устарел, переходите на `label`.
- Каждый сегмент — кнопка с `aria-pressed`, переход между ними — `Tab`.

## Делай / не делай

| Делай | Не делай |
|---|---|
| 2–4 коротких варианта | Семь сегментов с переносом |
| Одинаковые по смыслу режимы | «День / Неделя / Настройки» |
| `soft` на стене и в «Столе» | `default` и `soft` рядом на одном экране |
| Новый вид — `variant` в дизайн-системе | `.my-page .vs-segment button { … }` на сайте |
