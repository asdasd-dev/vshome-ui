# Clock

Крупные цифры времени шрифтом `--vs-font-display` с моноширинными цифрами. Компонент только показывает переданный текст: время считает и обновляет страница.

## Когда применять

- Часы на стене в коридоре и на «Столе», в том числе ночной экран: `size="hero"`.
- Обратный отсчёт до встречи: «04:59» до Deimos PBR.
- Длительность или время, которое должно читаться с расстояния.

## Когда не применять

- Цифра с единицей и подписью («1 мин», «+7°») — [Stat](#/c/Stat).
- Время в строке списка или в подписи — обычный [Text](#/c/Text).
- Дата и время в таблице — [Table](#/c/Table) с форматом из `fmtDate`.

## Анатомия

1. Блок `div` с текстом из `children`: «10:46», «04:59».
2. Цифры одной ширины (`tabular-nums`): соседние элементы не дёргаются при смене минуты.

## Размеры

| `size` | Кегль | Когда |
|---|---|---|
| `lg` (по умолчанию) | `--vs-text-3xl`, 48px | часы в углу плитки, таймер |
| `xl` | `--vs-text-4xl`, 72px | главная цифра плитки |
| `hero` | вдвое больше `4xl`, межстрочный 1 | часы на весь экран, ночная стена |

## Варианты

- `weight` — `medium` (по умолчанию) или `semibold` для таймера, который должен быть заметнее.
- `tone="soft"` — цвет на 20% прозрачнее: ночной экран, часы, которые не должны спорить с содержимым.
- `align="center"` — текст по центру блока.

## В киоске

Кегль растёт на `--vs-scale` (1,25) вместе со всем внутри `.vs-kiosk`: `hero` на стене — 180px.

## Доступность

- Часы, которые обновляются каждую минуту, не объявляйте как живой регион: скринридер будет зачитывать каждую смену.
- Таймеру нужна подпись рядом («До Deimos PBR»): цифры без контекста непонятны.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Обновлять раз в 10–30 секунд и форматировать «ЧЧ:ММ» | Показывать секунды на стене |
| Подпись к таймеру рядом через [Text](#/c/Text) | Вписывать «осталось» в `children` |
| `tone="soft"` ночью | Перекрашивать часы своим `color` |
| Размер выбирать через `size` | Писать `.vs-clock { font-size: 200px }` на сайте |
