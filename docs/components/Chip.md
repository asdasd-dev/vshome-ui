# Chip

Капсула-фильтр: нажата или нет, может нести счётчик. `ChipGroup` собирает ряд чипов, из которых нажат ровно один, — выбор одного значения из списка. Одиночный `Chip` — независимый фильтр-переключатель или ссылка на отфильтрованную страницу.

## Когда применять

- Фильтр списка со счётчиками: статусы на доске задач «Inbox 4 · Doing 2 · Review 1» — `ChipGroup` с `count`.
- Категории в Ленте: «Молочка», «Овощи», «Бакалея» — `ChipGroup scroll`, если не помещаются в строку.
- Независимые фильтры, которые включаются по отдельности: «Только со скидкой», «Есть в наличии» — несколько `Chip` с `pressed`.
- Фильтр, который меняет адрес страницы: `Chip href`, текущий отмечается `pressed`.

## Когда не применять

- Два–четыре равноправных режима одного вида («День / Неделя / Месяц») — [Segment](#/c/Segment).
- Действие, а не фильтр — [Button](#/c/Button) `size="sm"`.
- Ярлык без нажатия (статус, тег товара) — [Tag](#/c/Tag) или [Badge](#/c/Badge).
- Длинный список вариантов в форме — [Select](#/c/Select).

## Анатомия

1. Капсула с рамкой `--vs-line`, текст `--vs-muted`.
2. Подпись (`children` или `label` у опции группы), одна строка.
3. Счётчик `count` — [Badge](#/c/Badge): `muted` у обычного чипа, `accent` у нажатого.

## Размеры

- `md` — по умолчанию.
- `sm` — текст `xs`, без вертикальных отступов: строки таблиц, плотные шапки.

`ChipGroup` передаёт `size` всем своим чипам; `scroll` убирает перенос и включает горизонтальную прокрутку без полосы.

## Состояния

- Наведение — лёгкое затемнение, только на устройствах с указателем.
- Фокус — кольцо `--vs-focus-ring`.
- `pressed` — рамка и текст `--vs-accent`, фон `--vs-accent-tint`, полужирный; уходит в `aria-pressed`. Если `pressed` не задан вовсе, чип не переключатель, `aria-pressed` нет.
- С `href` нажатый чип отдаётся как `aria-current="page"` и выглядит так же, как нажатый чип-кнопка.
- `disabled` — прозрачность 50%, курсор «нельзя»; у чипа с `href` не работает. В `ChipGroup` — `disabled` у опции: «Архив», пока он пуст.

## В киоске

Внутри `.vs-kiosk` текст чипа `md` через `--vs-chip-size` и `--vs-chip-leading`, отступы растут с `--vs-scale`. На сайте ничего не меняйте.

## Доступность

- `ChipGroup` — `role="group"` с `aria-label` из обязательного `label`: «Статус задачи», «Категория».
- Счётчик читается вместе с подписью: «Inbox 4».
- Чип с `href` — обычная ссылка, переход работает с клавиатуры и открывается в новой вкладке.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Первым вариантом группы — «Все» | Группа, где ничего не выбрано |
| `scroll` для категорий на телефоне | Три строки переносов из чипов |
| `count` с реальным числом | `count={0}` у каждого пустого фильтра без нужды |
| `Chip href` для фильтра в адресе | `onClick` с ручной сменой `location` |
| Менять вид через `--vs-chip-*` в дизайн-системе | `.board .vs-chip { border: none }` на сайте |
