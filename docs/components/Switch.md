# Switch

Тумблер вкл/выкл, который применяется сразу, без кнопки «Сохранить». Видимой подписи у компонента нет: `label` — только для скринридера, текст рядом ставит раскладка, обычно строка [ControlList](#/c/ControlList).

## Когда применять

- Состояние устройства или правила: «Свет в коридоре», «Подогрев пола», «Автополив».
- Настройка, которая действует сразу: «Уведомления о встречах» в «Столе», «Показывать архив» на доске.
- Тумблер внутри кликабельной плитки или строки: клики по нему не всплывают, плитка не откроется.

## Когда не применять

- Изменение применится только после «Сохранить» в форме — [Checkbox](#/c/Checkbox).
- Выбор из нескольких режимов — [Segment](#/c/Segment).
- Действие с подписью, которое держит состояние («Ночной») — [Button](#/c/Button) с `pressed` или [SplitButton](#/c/SplitButton).
- Отметка пункта списка («куплено») — [Checkbox](#/c/Checkbox).

## Анатомия

1. Иконка `icon` слева — необязательна, любой узел, скрыта от скринридера.
2. Дорожка — серая, у включённого `--vs-accent`.
3. Ручка — круг `--vs-knob`, съезжает вправо при `checked`.

## Размеры

- `md` — 40 × 22 px, по умолчанию.
- `sm` — 30 × 18 px, иконка шрифтом `xs`; добавляет невидимые отступы вокруг, чтобы в него было легче попасть в плотной строке.

## Состояния

- Фокус — кольцо `--vs-focus-ring` вокруг дорожки.
- `checked` — дорожка `--vs-accent`, ручка справа; переход анимируется, кроме режима уменьшенного движения.
- `disabled` — прозрачность 50%, курсор «нельзя»: удобно на время запроса к устройству.
- `title` — всплывающая подсказка, например «Последнее изменение 14:02».

## В киоске

Внутри `.vs-kiosk` тумблер 56 × 32 px с ручкой 24 px (и всё × масштаб) — через `--vs-switch-*` на `.vs-kiosk`. Размер `sm` в киоске тоже получает эти размеры. На сайте ничего не меняйте.

## Доступность

- `<input type="checkbox" role="switch">`: скринридер слышит «переключатель, включён».
- `label` обязателен и должен совпадать с видимым текстом рядом: «Свет в коридоре».
- Переключается пробелом.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Применять сразу по `onChange` | Тумблер и кнопка «Сохранить» под ним |
| `disabled` на время запроса, затем новое `checked` из ответа | Оставлять тумблер включённым, если устройство не ответило |
| Видимая подпись в [ControlList](#/c/ControlList) | Тумблер без текста рядом |
| Размеры — через `--vs-switch-*` в дизайн-системе | `.wall .vs-switch input { width: … }` на сайте |
