# PageHeader

Шапка страницы сайта: заголовок `h1`, подзаголовок, кнопка «Назад» слева, действия справа и строка под ними для поиска или фильтров.

## Когда применять

- Верх страницы доски задач, Ленты, дашборда vshome.space.
- Страница одного объекта с возвратом: «T-411 · Каталог дизайн-системы» со стрелкой назад.
- Шапка, которая остаётся на месте при прокрутке длинного списка: `sticky`.

## Когда не применять

- Заголовок раздела внутри страницы — [SectionHeader](#/c/SectionHeader).
- Заголовок шторки — `head` у [Sheet](#/c/Sheet).
- Подпись блока на стене — `label` у [Tile](#/c/Tile).
- Заголовок графика — `title` у [ChartCard](#/c/Charts).

## Анатомия

1. `lead` — слева, обычно [IconButton](#/c/IconButton) `arrow-left` «Назад».
2. `title` — `h1`, одна строка, не помещается — многоточие.
3. `sub` — строка под заголовком, мельче и серее: статус, счётчик, адрес.
4. `actions` — справа, не сжимаются: [Button](#/c/Button), [Segment](#/c/Segment), [IconButton](#/c/IconButton).
5. `children` — строка во всю ширину под заголовком: поиск, [Tabs](#/c/Tabs), фильтры.

## Варианты

| `tone` | Когда |
|---|---|
| `default` (по умолчанию) | фон страницы и линия снизу |
| `accent` | глубокий синий фон `--vs-header-accent-bg` (градиент, насыщенный в обеих темах), белый текст `--vs-on-header-accent`: главная страница сайта, брендовая шапка. [Tabs](#/c/Tabs) в `children` сами берут белые цвета |

`plain` устарел и работает как `default`.

## Размеры и расположение

- `size`: `md` по умолчанию; `lg` — заголовок шрифтом витрин `--vs-font-display` размера `--vs-text-xl`: главная страница сайта, доска задач.
- `actionsAlign`: `end` по умолчанию — действия у правого края; `start` — сразу за заголовком, а их блок занимает остаток строки: переключатель вида рядом с «Задачи», фильтры справа через `Cluster justify="between"`.

## Состояния

- `sticky` — прилипает к верху при прокрутке, поверх содержимого (`--vs-z-header`).
- `contained` (`sm`, `md`, `lg`) — содержимое шапки по ширине [Container](#/c/Container) того же размера: логотип и вкладки встают над колонкой страницы, фон остаётся во всю ширину. Ставьте тот же размер, что у `Container` с контентом.


## Новое в 0.26

- Внутри [Container](#/c/Container) шапка не добавляет своих боковых полей: поля и безопасные зоны по бокам даёт `Container`, края заголовка и действий совпадают с краем содержимого. Шапку с цветным фоном на всю ширину ставьте вне `Container`.

## Новое в 0.24

- Отступ сверху — `max(env(safe-area-inset-top), --vs-safe-top)`: если PWA на старом iPhone получает нулевой системный отступ, сайт задаёт `--vs-safe-top` (например, 59px) на `:root`, своих отступов в шапке не нужно.

## Доступность

- `title` всегда `h1`: одна шапка на страницу.
- Кнопка в `lead` — [IconButton](#/c/IconButton) с `label="Назад"`.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Одна `PageHeader` на страницу | Шапка в каждой секции — там [SectionHeader](#/c/SectionHeader) |
| Короткий `title`, подробности в `sub` | Длинный заголовок, который режется многоточием |
| Поиск и вкладки в `children` | Вторая строка шапки своей вёрсткой под компонентом |
| 1–2 действия в `actions` | Пять кнопок справа на телефоне |
| Цвет шапки — `tone` | Писать `.vs-page-header { background: … }` на сайте |
