# Tile

Плитка киоска: прямоугольник на стене в коридоре или на «Столе» с подписью капсом сверху, содержимым и подвалом. Для обычных сайтов (доска, Лента, дашборд) нужна не плитка, а [Card](#/c/Card).

## Когда применять

- Один блок стены или «Стола»: «Встреча · 11:15», «Ждут тебя · 2», «Музыка», «Свет», «Mattermost».
- Блок, где подпись важнее заголовка: короткое имя раздела капсом, рядом цифра или кнопка в `aside`.
- Список, который не помещается в ячейку сетки киоска: `scroll`, прокрутка без полосы с затуханием краёв.

## Когда не применять

- Карточка задачи на доске, пост в Ленте, плитка сервиса на дашборде — [Card](#/c/Card).
- Кликабельный блок целиком — [Card](#/c/Card) с `onClick` или `href`: у `Tile` нет клика.
- Заголовок раздела на странице сайта — [SectionHeader](#/c/SectionHeader).
- Карточка с графиком — [ChartCard](#/c/Charts).

## Анатомия

1. Контейнер `section` — фон `--vs-surface-1`, скругление `--vs-radius-xl`, отступ `--vs-space-5`, без рамки.
2. Подпись `label` — мелкий капс серым; связана с плиткой через `aria-labelledby`.
3. `aside` — справа от подписи: счётчик, время, маленькая кнопка. Показывается только вместе с `label`.
4. Тело — колонка с отступом `--vs-space-3`, занимает всё свободное место.
5. Подвал `footer` — прижат к низу плитки: кнопки «Войти», управление музыкой.

## Варианты

| `tone` | Когда |
|---|---|
| `default` | обычное состояние |
| `warn` | требует внимания сейчас: встреча через минуту, агент ждёт ответа; подпись и `aside` оранжевые |
| `danger` | сломалось: Мак не на связи, автодеплой упал; подпись красная |

## Состояния

- `dimmed` — прозрачность 50%: блок неактуален сейчас (Mattermost без новых сообщений), но место на стене за ним остаётся.
- `scroll` — тело прокручивается, полоса скрыта; сверху и снизу появляется затухание, если есть что прокручивать. Плитке нужна высота от родителя (ячейка сетки стены), иначе она растёт по содержимому и прокрутки нет.

## В киоске

Плитка рассчитана на киоск: внутри `.vs-kiosk` все отступы и шрифты растут на `--vs-scale` (1,25), своих переменных у плитки нет. На сайте её не используйте.

## Доступность

- `label` обязателен по смыслу: без него у `section` нет имени, скринридер читает «регион» без названия.
- Цифры в `aside` идут с `tabular-nums`, не прыгают при обновлении.
- Кнопки в `footer` и `aside` — обычные [Button](#/c/Button) и [IconButton](#/c/IconButton) с подписями.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Короткий `label`: «Музыка», «Свет», «Сегодня» | Длинный заголовок-предложение в подписи |
| `tone="warn"` на время события, потом обратно `default` | Держать плитку оранжевой постоянно |
| `scroll` для длинного списка в ячейке стены | Обрезать список руками или растягивать сетку |
| Карточки сайтов собирать на [Card](#/c/Card) | Ставить `Tile` на доску или в Ленту |
| Менять вид через токены дизайн-системы | Писать `.wall .vs-tile { padding: … }` на сайте |

## Новое в 0.37

- `switcher` — переключатель в заголовке плитки вместо подписи (`Segment soft sm`): одна плитка показывает один из нескольких видов (например, «Mattermost» и «Новости»). Заголовок не прокручивается вместе с содержимым. `aside` остаётся справа.

## Новое в 0.39

- `backdrop` — адрес картинки фоном плитки: затемнена градиентом к цвету плитки, текст поверх читается. С 0.43 без размытия. Для «Музыки» — обложка трека. Картинка декоративная (`aria-hidden`).
