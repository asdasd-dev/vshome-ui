# Button

Кнопка запускает действие: сохранить, открыть, отправить, переключить. Для перехода на другую страницу или адрес нужна не кнопка, а [Link](#/c/Link).

## Когда применять

- Действие на этой странице: «Сохранить», «Пропустить», «Погасить экраны».
- Переключатель с подписью, который держит состояние: `pressed` («Ночной», «Сон»).
- Главное действие формы или шторки: одна кнопка `primary` на экран.

## Когда не применять

- Переход по адресу — [Link](#/c/Link) или `Card href`.
- Только иконка без подписи — [IconButton](#/c/IconButton).
- Действие плюс второе действие рядом («включить» и «открыть настройки») — [SplitButton](#/c/SplitButton).
- Выбор одного варианта из нескольких — [Segment](#/c/Segment) или [ChipGroup](#/c/Chip).
- Вкл/выкл без подписи-действия — [Switch](#/c/Switch).

## Анатомия

1. Контейнер — фон и скругление из переменных `--vs-button-*`.
2. Иконка слева (`icon`) или спиннер при `loading`.
3. Подпись — глагол или существительное действия, одна строка, не переносится.
4. Лампа (`indicator="lamp"`) — точка в левом отступе у нажатой кнопки, ширина не меняется.

## Варианты

| Вариант | Когда |
|---|---|
| `secondary` (по умолчанию) | обычное действие |
| `primary` | главное действие экрана, одно |
| `ghost` | второстепенное действие рядом с главным, в шапках и строках |
| `danger` | необратимое или разрушающее действие |
| `warn` | действие, требующее внимания сейчас («2 в MM») |

## Размеры и форма

- `sm` — в плотных местах: шапки, строки таблиц, углы плиток.
- `md` — по умолчанию.
- `lg` — главное действие на телефоне, крупные формы.
- `block` — на всю ширину контейнера (подвал шторки, мобильная форма).
- `shape="pill"` — капсула вне киоска; в киоске все кнопки капсулы сами.

## Состояния

- Наведение — лёгкое затемнение, только на устройствах с указателем.
- Фокус — кольцо `--vs-focus-ring`.
- `pressed` — фон `--vs-accent-soft`; с `indicator="lamp"` вместо фона жёлтая точка.
- `disabled` — прозрачность 50%, курсор «нельзя»; объясните рядом, почему недоступно.
- `loading` — спиннер вместо иконки, кнопка недоступна, `aria-busy`, курсор «ожидание».

## В киоске

Внутри `.vs-kiosk` кнопка становится капсулой без рамки, высота 44 × масштаб, текст `md`. Ничего не меняйте на сайте — всё задаётся переменными на `.vs-kiosk`.

## Доступность

- Подпись видна всегда; если её нет — это [IconButton](#/c/IconButton) с `label`.
- `type="button"` по умолчанию, `submit` — только в формах явно.
- `pressed` отдаётся как `aria-pressed`, скринридер слышит «нажата».

## Делай / не делай

| Делай | Не делай |
|---|---|
| Одна `primary` на экран | Три синие кнопки рядом |
| «Сохранить», «Открыть ворота» | «ОК», «Да», «Нажмите здесь» |
| `loading` на время запроса | Менять подпись на «Сохраняю…» вручную |
| `variant="danger"` + подтверждение в [Sheet](#/c/Sheet) | Удалять по одному касанию |
| Перебивать вид через переменные `--vs-button-*` в дизайн-системе | Писать `.my-page .vs-button { … }` на сайте |
