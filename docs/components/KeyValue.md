# KeyValue

Сетка пар «название — значение» с необязательной подсказкой под значением: сводка по сервису, по товару, по месяцу расходов.

## Когда применять

- 2–8 равноправных показателей одного объекта: у VPN — статус, трафик, аптайм; у товара Ленты — цена, скидка, вес.
- Значение, которому нужна короткая подсказка: «−18%» с «к прошлому месяцу».
- Значение со статусом: тон у отдельной пары (`items[].tone`).

## Когда не применять

- Одна главная цифра блока — [Stat](#/c/Stat).
- Одинаковые показатели у нескольких объектов (цены пяти товаров) — [Table](#/c/Table).
- Список дел или событий — [List](#/c/List).

## Анатомия

1. Название (`label`) — 12 px серым над значением.
2. Значение (`value`) — полужирное, моноширинные цифры.
3. Подсказка (`hint`) — 12 px серым под значением.
4. Сетка — `cols` колонок одинаковой ширины.

## Размеры и колонки

| Проп | Значение | Когда |
|---|---|---|
| `size="md"` (по умолчанию) | значение 20 px | сводка в карточке или плитке |
| `size="sm"` | значение 14 px | подробности в шторке, второй уровень |
| `cols` | 1–4, по умолчанию 2 | сколько пар в ряд; на телефоне — не больше 2 |

## Тоны значения

`default`, `muted`, `ok`, `warn`, `danger` — задаются на каждой паре отдельно и красят только значение. `muted` — нет данных («—»), остальные — статус.

## В киоске

Отступы и текст умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`). Число колонок не меняется: 4 колонки на стене дают узкие ячейки, берите 2–3.

## Доступность

- Размечено `dl`/`dt`/`dd`: скринридер читает пару как термин и определение.
- Подсказка — второй `dd` той же пары и читается после значения.
- Статус не только цветом: «не в сети», а не красный «0».

## Делай / не делай

| Делай | Не делай |
|---|---|
| Короткие названия: «Трафик», «Аптайм» | «Объём трафика за текущий месяц» |
| `value="—"` с `tone="muted"`, если данных нет | Пустая ячейка |
| Единицу в значении: «12,4 ГБ» | Единицу в названии и голое число |
| `cols={2}` на телефоне | `cols={4}` в узкой колонке |
| Менять вид через переменные дизайн-системы | Перебивать `.vs-kv__value` на сайте |
