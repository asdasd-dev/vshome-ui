# Layout

Три примитива раскладки: `Cluster` — ряд, `Stack` — колонка, `Divider` — линия между ними. Из них собирается всё внутри блоков: шапки карточек, ряды кнопок, подписи под цифрами.

## Правило

На сайтах своя вёрстка — только для раскладки страницы: сетка колонок доски, сетка стены, позиционирование панелей. Всё внутри блоков собирается из `Cluster`, `Stack` и `Divider` с отступами из шкалы. Свой `display: flex` с `gap: 10px` внутри карточки — это повод взять `Cluster`.

## Когда применять

- `Cluster` — элементы в ряд: кнопки «Отмена» и «Сохранить», заголовок и счётчик, теги репозиториев.
- `Stack` — элементы в колонку: заголовок и подпись, поля формы, карточки списка.
- `Divider` — разделить группы внутри одного блока: «Мак | бокс | роутер», разделы шторки.

## Когда не применять

- Сетка страницы, колонки доски, раскладка стены — своя вёрстка сайта (CSS grid).
- Список однотипных строк — [List](#/c/List).
- Строки «подпись — переключатель» — [ControlList](#/c/ControlList).
- Заголовок с текстом справа — [SectionHeader](#/c/SectionHeader).
- Линия между пунктами меню — `"separator"` в [ContextMenu](#/c/ContextMenu).

## Cluster

- `gap` — `1`, `2` (по умолчанию), `3`, `4`, `6`, `8`: шаги `--vs-space-*`.
- `align` — `center` (по умолчанию), `baseline` (цифра и подпись разного кегля), `start`, `end`, `stretch`.
- `justify` — `start`, `center`, `between` (заголовок слева, кнопка справа), `end` (кнопки формы справа).
- `wrap` — переносить на следующую строку, когда не помещается: теги, фильтры.
- `rigid` — дети не сжимаются и не переносят текст: короткие метки, которые нельзя ломать.
- `as` — `div`, `span`, `header`, `footer`.

## Stack

- `gap` — та же шкала, по умолчанию `2`.
- `align` — `start`, `center`, `end`, `stretch`; без него дети растягиваются на ширину колонки.
- `justify` — `start`, `center`, `between`, `end`: раскладка по высоте, когда у `Stack` есть своя высота (подвал карточки прижат вниз — `between`).
- `as` — `div` или `span`; `span` нужен внутри кнопок и ссылок, например в кликабельной [Card](#/c/Card).

## Divider

- Горизонтальная линия `--vs-line` по умолчанию, в `Stack`.
- `vertical` — вертикальная, в `Cluster`, с отступом по бокам `--vs-space-1`.

## В киоске

Внутри `.vs-kiosk` отступы шкалы растут на `--vs-scale`, раскладка остаётся той же.

## Доступность

- `Divider` отдаётся как `role="separator"` с ориентацией.
- Порядок детей — порядок чтения и фокуса; не меняйте его визуально через `order`.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `<Cluster justify="between">` для «заголовок — кнопка» | `<div style={{ display: "flex", justifyContent: "space-between" }}>` |
| Отступы из шкалы `gap="3"` | `margin-top: 13px` на ребёнке |
| Сетку страницы — своим CSS сайта | Строить сетку доски из вложенных `Cluster` |
| `Stack as="span"` внутри `button` и `a` | `div` внутри кнопки |
| Не хватает отступа в шкале — добавить его в дизайн-систему | Перебивать `.vs-cluster { gap: … }` на сайте |
