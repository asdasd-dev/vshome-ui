# Prose

Обёртка для текста статьи: задаёт кегль, межстрочный, ширину строки до 72 знаков и стили обычных тегов — заголовков, списков, ссылок, цитат, кода, таблиц. Содержимое — дети или готовый HTML в `html`.

## Когда применять

- Тело поста в Ленте, пришедшее HTML-ом.
- Заметка из волта, отрисованная из markdown.
- Длинный текст справки на сайте: описание задачи на доске, инструкция.

## Когда не применять

- Одна строка или подпись — [Text](#/c/Text).
- Короткая выдержка из поста с обрезкой — [Excerpt](#/c/Excerpt).
- Пары «название — значение» — [KeyValue](#/c/KeyValue).
- Табличные данные с сортировкой и колонками — [Table](#/c/Table).

## Анатомия

1. Контейнер `div`, `max-width: 72ch`, кегль `--vs-text-md`.
2. Заголовки `h1`–`h4` — свои отступы сверху; у первого элемента отступ сверху снят, у последнего — снизу.
3. Абзацы, списки, цитаты, `pre`, таблицы — отступ `--vs-space-3` снизу.
4. Ссылки — `--vs-accent` с подчёркиванием.
5. `code` и `pre` — серый фон `--vs-surface-2`, `pre` прокручивается вбок.
6. Цитата — серая полоса слева и серый текст.
7. Таблица — на всю ширину, мельче, серые заголовки.

## Состояния

- `html` — вставляется как есть через `dangerouslySetInnerHTML`; если передан, `children` не выводятся.

## В киоске

Кегль и отступы растут на `--vs-scale` внутри `.vs-kiosk`. На стене длинный текст обычно не нужен.

## Доступность

- Уровни заголовков внутри текста продолжают уровни страницы: под [PageHeader](#/c/PageHeader) текст начинается с `h2`.
- Ссылки в тексте — со смыслом: «на сайте», а не «здесь».

## Делай / не делай

| Делай | Не делай |
|---|---|
| `html` только из своего доверенного источника или после очистки | Вставлять HTML из чужого поста без санитайзера |
| Ширина строки — та, что задаёт `Prose` | Растягивать текст на весь экран |
| Ссылки в тексте ставить `linkify` из пакета | Собирать `<a>` строками вручную |
| Вид менять через токены дизайн-системы | Писать `.post .vs-prose h2 { … }` на сайте |
