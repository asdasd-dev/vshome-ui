# Frame

Чужая страница внутри своей: доска задач на «Столе», страница сервиса в плитке. Без рамки браузера, со скруглением; в плитке растягивается на всё тело.

## Когда применять

- Готовая страница другого сервиса vshome, которую не нужно пересобирать виджетами: доска задач в режиме «Задачи» на «Столе».

## Когда не применять

- Данные, которые можно взять из API и показать [List](#/c/List) или [Stat](#/c/Stat): виджет из компонентов быстрее и выглядит как остальная страница.
- Картинка — [Artwork](#/c/Artwork) или `img` в [Prose](#/c/Prose).

## Анатомия

1. `iframe` без рамки, скругление `--vs-radius-md`, фон `--vs-surface-0`, пока страница грузится.
2. Ширина 100%, высота — всё свободное место родителя-флекса (`flex: 1`). В [Tile](#/c/Tile) это тело плитки под подписью.

## Свойства

- `src` — адрес страницы. Страница должна разрешать встраивание: `frame-ancestors` в её CSP перечисляет сайт, на котором стоит `Frame`, и все сайты выше него.
- `title` — обязательное название для скринридера: «Доска задач».
- `loading` — `lazy` (по умолчанию) или `eager` для первого экрана.

## Состояния

- Страница запретила встраивание или требует входа (редирект Authelia с `X-Frame-Options: DENY`) — браузер показывает свою ошибку внутри рамки. Лечится на стороне страницы или входом.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Класть в [Tile](#/c/Tile) с подписью | Ставить голый `iframe` со своим CSS |
| Давать `title` по смыслу страницы | Оставлять `title` пустым |
| Встраивать свои сервисы vshome | Встраивать чужие сайты |
