# Badge

Счётчик в маленькой капсуле или точка без числа: сколько непрочитанного, сколько ждёт. Ставится рядом с подписью, иконкой или в углу плитки.

## Когда применять

- Число, которое меняется и требует реакции: 2 агента ждут ответа, 5 сообщений в Mattermost, 3 задачи в inbox.
- Точка (`dot`) — «есть новое», когда число неважно: новые новости на стене.
- Большие числа с `max`: при `max={99}` число 140 выводится как «99+».

## Когда не применять

- Статус или категория словом: «doing», «скидка», «VPN» — [Tag](#/c/Tag).
- Цвет состояния сервиса без текста — [StatusDot](#/c/Legend).
- Крупная цифра как главное содержание блока — [Stat](#/c/Stat).
- Число в заголовке раздела — проп `count` у [SectionHeader](#/c/SectionHeader).

## Анатомия

1. Капсула высотой 18 px (× масштаб), цифры моноширинные, текст 11 px полужирный.
2. Содержимое — число или короткая строка в `children`.
3. Точка (`dot`) — круг 8 px без содержимого.

## Тоны

| Тон | Когда |
|---|---|
| `accent` (по умолчанию) | обычный счётчик нового |
| `warn` | ждут ответа, срок близко: «Ждут тебя · 2» |
| `danger` | сбой или просрочка: упавшие сервисы, просроченные дела |
| `ok` | готово, подтверждено |
| `muted` | справочное число, на которое реагировать не нужно |

## Состояния

- `max` — только для числового `children`: всё больше `max` выводится как «`max`+».
- Без `children` и без `dot` Badge не выводится. Ноль не показывайте: при пустом счётчике не рендерите Badge вовсе.

## В киоске

Размер капсулы и текста умножается на `--vs-scale` (1,25 внутри `.vs-kiosk`). Остальное не меняется.

## Доступность

- Голое число скринридер прочитает без смысла. Дайте `label`: «5 непрочитанных в Mattermost»; с ним Badge получает `role="img"` и читается подписью вместо числа.
- Для `dot` `label` обязателен по смыслу: без него точка будет `role="img"` без имени.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `max={99}` для потока сообщений | Выводить «1284» в капсуле |
| Не рендерить при нуле | Показывать серый «0» |
| `label="2 агента ждут"` | Голое число без подписи для скринридера |
| Слово-статус — в [Tag](#/c/Tag) | `<Badge>doing</Badge>` |
| Менять вид через `--vs-badge-*` в дизайн-системе | Перебивать `.vs-badge` на сайте |
