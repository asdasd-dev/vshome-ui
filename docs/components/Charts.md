# Charts

Графики пакета `@vshome/ui/charts`: `LineChart` — линии по времени с равным шагом, `TimeChart` — точки и линии по произвольным моментам времени, `StackedBars` — столбики с накоплением по дням или месяцам, `ChartCard` — рамка с заголовком, подписью и легендой. Подключаются отдельным импортом из `src/charts`, со своим CSS.

## Когда применять

- `LineChart` — величина во времени с равным шагом: задержка выходов VPN каждые 30 минут, время ночного синка.
- `TimeChart` — замеры в произвольные моменты: цена товара в Ленте по дням, когда её видели, температура по датчику с пропусками.
- `StackedBars` — сумма по дням или месяцам из нескольких частей: расход Claude Code на Маке и боксе, расходы по категориям.
- `ChartCard` — любой график на дашборде vshome.space или в мониторинге: заголовок, подпись, легенда, переключатель периода.

## Когда не применять

- Одна текущая цифра — [Stat](#/c/Stat).
- Доля от целого в одной полосе — [SplitBar](#/c/Progress).
- Точные значения, которые нужно читать и сравнивать — [Table](#/c/Table).
- Метрики продакшена с выборкой и масштабом — Grafana, а не своя страница.

## Анатомия

1. `ChartCard` — фон `--vs-panel`, рамка, `title`, серый `sub`, `extra` (переключатель периода, таблица), легенда `legend` из `{ name, color, extra }`, график в `children`. Та же легенда отдельно — `ChartLegend` (не путать с основным [Legend](#/c/Legend)).
2. Сетка — пять горизонтальных линий, подписи оси Y слева; у `LineChart` единица `unit` только у верхней.
3. Ось X — у `LineChart` метки на полночь каждого дня («01.10»), `xEvery` прореживает их; у `TimeChart` четыре равные метки от первой точки до последней или до `now`; у `StackedBars` подпись под каждым вторым столбиком.
4. Подсказка — при наведении или касании: время или день, значение каждого ряда, у столбиков — сумма.

## LineChart

- `t0` и `step` — начало ряда и шаг точки в секундах; `series` — ряды `{ name, color, data, fmt }`, `null` в `data` — пропуск.
- Линия рвётся на пропусках; `connect` соединяет точки через пропуски и рисует каждую точку кружком — для редких замеров.
- `bands` — красные полосы на отрезках `[от, до]`, подпись в подсказке `bandLabel` («VPN не работал»). `outageBands(alive)` строит их из ряда доступности, где 0 — не работал.
- `marks` — вертикальные отметки событий: сплошная оранжевая — выкатка, `dashed` — перезапуск.
- `yMax` — фиксированный верх шкалы, иначе округлённый максимум данных.
- `note` — дополнительная строка подсказки по индексу точки.
- `label` — подпись графика для скринридера, `className` — класс обёртки.

## TimeChart

- `series` — ряды `{ name, color, points, dots, area, fmt }`; `points` — пары `[время, значение]`, время в секундах Unix, порядок любой, шаг любой.
- `dots` — только точки, без линии: редкие наблюдения, между которыми нельзя провести линию (цена товара в дни, когда её видели). `area` — заливка под линией.
- `refLines` — горизонтальные линии `{ y, label, color, dashed }`: медиана цены, порог, цель. По умолчанию пунктир серым, подпись справа над линией.
- `now` — вертикальная линия «сейчас»; растягивает ось X до этого момента, даже если последняя точка раньше.
- `yFrom` — `zero` (по умолчанию) — шкала от нуля; `data` — от 90% минимума данных, когда важны колебания, а не величина (температура 20–23°).
- `unit` — единица у верхней подписи оси Y; `xFormat` — подписи оси X (по умолчанию «15.10»); `tipFormat` — время в подсказке (по умолчанию «15 окт. 2026 г.»), для почасовых данных добавьте часы.
- Подсказка берёт ближайшую по времени точку и показывает ряды, у которых точка ровно в этот момент.
- Подписи оси Y округляются до целых: для значений меньше 10 (рейтинг 4,5) шкала грубая.

## StackedBars

- `labels` — дни в формате `YYYY-MM-DD`; `series` — ряды `{ name, color, data }` одинаковой длины; `fmt` — формат значений на оси и в подсказке.
- `xFormat` — подпись столбика на оси и в подсказке из строки `labels`; по умолчанию «01.10». Для расходов по месяцам — «май», «июн».
- Верхний сегмент столбика скруглён, между сегментами зазор 2px.
- `label` и `className` — как у `LineChart`.

## Цвета

Цвета рядов — из `chartPalette` по порядку: синий, оранжевый, зелёный, жёлтый, розовый. Один и тот же ряд на разных графиках — один цвет.

## В киоске

Высота графика фиксирована в пикселях, подписи и легенда растут на `--vs-scale`. Для стены графики не рассчитаны: там нужна цифра [Stat](#/c/Stat).

## Доступность

- График — `svg role="img"`; `label` даёт ему имя: «Пинг VPN за неделю». Сами значения скринридер не читает: всё важное (доступность 97%, сумма за неделю) дублируйте в `sub` или `legend` `extra`.
- Ряды различаются только цветом: держите их не больше трёх и подписывайте в легенде.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Любой график — внутри `ChartCard` | График без заголовка и легенды |
| Цвета из `chartPalette` | Подбирать цвета рядов на каждой странице |
| Пропуск данных — `null` | Подставлять 0 вместо пропуска |
| Редкие замеры — `TimeChart` с `dots` | Растягивать редкие точки в `LineChart` с шагом в минуту |
| Отключения — `bands`, события — `marks` | Отдельный ряд «0/1» на той же шкале |
| Вид менять через переменные `--vs-chart-*` | Писать `.vs-chart-grid { stroke: … }` на сайте |
