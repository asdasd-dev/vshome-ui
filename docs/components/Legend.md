# Legend

Подписи к цветам: `Legend` объясняет, какой цвет на графике или полосе что значит, `StatusDot` — цветная точка состояния рядом с названием.

## Когда применять

- `Legend` — под графиком расходов, под [SplitBar](#/c/Progress), рядом с картой сервисов: «Еда», «Подписки», «план» пунктиром.
- `StatusDot` — состояние объекта в строке: сервис в сети или упал, агент работает или ждёт, VPN подключён.
- `StatusDot` с `pulse` — идёт прямо сейчас: встреча в эфире, агент работает.

## Когда не применять

- Состояние, которое надо прочитать словом, — [Tag](#/c/Tag).
- Счётчик нового — [Badge](#/c/Badge) с `dot` или числом.
- Предупреждение с объяснением — [Banner](#/c/Banner).

## Анатомия

1. `Legend` — строка элементов с переносом, текст 12 px серым.
2. Образец цвета (`shape`): `dot` — круг (по умолчанию), `square` — квадрат для столбцов и полос, `line` — линия для графика, `dash` — пунктир для плана или прогноза.
3. Цвет — `tone` из набора дизайн-системы или `color`, если на графике свой.
4. `StatusDot` — круг 8 px цвета `tone`.

## Тоны

| Тон | `Legend` | `StatusDot` |
|---|---|---|
| `accent` | основная серия | активен, выбран |
| `ok` | в норме | в сети |
| `warn` | близко к пределу | ждёт, деградирует |
| `danger` | превышение | упал |
| `muted` | остаток, прочее | выключен, нет данных |
| `violet`, `pink`, `gold` | дополнительные серии | категория без статусного смысла |

У `StatusDot` `tone` по умолчанию `ok`.

## Состояния

- `pulse` — точка мигает; при `prefers-reduced-motion` не мигает.

## В киоске

Размеры образцов и точки умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`), своих правил нет.

## Доступность

- `StatusDot` без `label` скрыт от скринридера: состояние должно быть в тексте рядом или в `label` («в сети», «не отвечает»).
- `Legend` — список `ul`, подписи читаются как текст; образцы цвета декоративные.
- Не различайте серии только красным и зелёным: добавляйте `shape` или подпись.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Те же тоны в [SplitBar](#/c/Progress) и Legend | Легенда с цветами, которых нет на графике |
| `shape="dash"` для плана, `line` для факта | Пять кругов одного оттенка |
| `StatusDot tone="danger" label="не отвечает"` | Красная точка без слова и без `label` |
| `pulse` только для «идёт сейчас» | Мигающие точки у всех сервисов |
| Менять цвета через `--vs-*` тоны в дизайн-системе | Перебивать `.vs-legend__swatch` на сайте |
