# IconButton

Круглая кнопка только с иконкой: закрыть шторку, запустить трек, добавить карточку. Подпись не видна, но обязательна: `label` уходит в `aria-label` и во всплывающую подсказку.

## Когда применять

- Действие, которое иконка объясняет без слов: «Закрыть» (`close`), «Назад» (`arrow-left`), плеер на стене (`play`, `pause`, `prev`, `next`).
- Плотные места, где подпись не помещается: шапка шторки, угол карточки задачи, строка списка покупок.
- Главное действие-иконка экрана: «Добавить задачу» (`plus`) с `variant="primary"`.

## Когда не применять

- Иконка не очевидна без подписи («Ночной», «Погасить экраны») — [Button](#/c/Button) с `icon` и текстом.
- Переход по адресу — [Link](#/c/Link).
- Действие с выпадающими настройками рядом — [SplitButton](#/c/SplitButton).
- Вкл/выкл состояния — [Switch](#/c/Switch) или [Button](#/c/Button) с `pressed`.

## Анатомия

1. Круглый контейнер `--vs-surface-2` (у `primary` — `--vs-accent`, у `ghost` — прозрачный), минимум 44 × 44 px с учётом `--vs-scale`.
2. Иконка из набора `icon` — одно из имён `IconName`, или спиннер при `loading`.

## Варианты

| Вариант | Когда |
|---|---|
| `secondary` (по умолчанию) | обычное действие: закрыть, назад, следующий трек |
| `primary` | главное действие экрана, одно |
| `ghost` | без фона: в строке списка, в углу карточки, рядом с текстом |

`plain` устарел и работает как `secondary`.

## Размеры

- `sm` — 32 px, иконка `sm`. Строки таблиц и списков, где 44 px не помещается; на телефоне оставляйте `md`.
- `md` — 44 px, иконка `md`. По умолчанию, подходит и для пальца, и для мыши.
- `lg` — 56 px, иконка `lg`. Главная кнопка плеера на стене, плавающая «Добавить» на телефоне.

## Состояния

- Наведение — лёгкое затемнение, только на устройствах с указателем.
- Фокус — кольцо `--vs-focus-ring` с отступом 2 px.
- `disabled` — прозрачность 50%, курсор «нельзя».
- Нажатие — кнопка сразу темнеет и чуть сжимается (`--vs-press`, `--vs-press-scale`), на касание тоже: на планшете наведения нет.
- `loading` — спиннер вместо иконки, кнопка недоступна, `aria-busy`, курсор «ожидание».
- Ждёт ответа — `onClick` вернул Promise: спиннер, `aria-busy`, кнопка остаётся доступной: повторное нажатие уходит, спиннер крутится, пока не выполнены все. Выполнился с `false` или отказом — красная обводка `--vs-fail-ring` на 2 с. Отдавайте Promise запроса из `onClick`, `loading` руками для этого не нужен.
- `pressed` — переключатель: `aria-pressed`, фон `--vs-accent-soft`, иконка акцентом. Звёздочка «в избранном» в углу [Snippet](#/c/Snippet).

## В киоске

Размеры заданы через `--vs-scale`, поэтому внутри `.vs-kiosk` кнопка сама становится больше: 55 px у `md` и 70 px у `lg`. Отдельных переменных у компонента нет.

## Доступность

- `label` обязателен: «Закрыть», «Следующий трек», а не «Иконка» или «Кнопка».
- `type="button"` по умолчанию; остальные атрибуты `<button>` (`onClick`, `disabled`, `aria-*`) передаются как есть.
- Для переключателя («Пауза» ↔ «Играть») меняйте и `icon`, и `label` вместе.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `label="Закрыть"` у `close` | `label="close"` или пустая строка |
| Одна `primary` на экран | Ряд синих кругов в шапке |
| Promise запроса из `onClick` | Подменять `icon` на спиннер вручную |
| `lg` для главной кнопки плеера | `lg` в строке списка покупок |
| Менять фон через переменные или новый `variant` в дизайн-системе | `.my-page .vs-icon-button { background: … }` на сайте |
| [Button](#/c/Button) с текстом, если иконка спорная | Угадывать смысл иконки по подсказке при наведении |
