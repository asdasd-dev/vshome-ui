# Text

Текст из шкалы дизайн-системы: роль (`variant`) задаёт размер, высоту строки и начертание, тон (`tone`) — цвет. Любая строка интерфейса вне готовых компонентов набирается через Text, а не через `<p>` со своими размерами.

## Когда применять

- Заголовок страницы или шторки, подпись под цифрой, пояснение в плитке.
- Строка с тоном: «На сегодня всё» (`muted`), «VPN не в сети» (`danger`).
- Текст, который надо обрезать до 1–3 строк: название новости на стене, заголовок задачи на доске.

## Когда не применять

- Длинный текст с абзацами, списками и ссылками из markdown — [Prose](#/c/Prose).
- Описание, которое на стене обрезается и открывается целиком по касанию, — [Excerpt](#/c/Excerpt).
- Крупная цифра с единицей: «48 230 ₽», «12 мин» — [Stat](#/c/Stat).
- Заголовок раздела с счётчиком и действием — [SectionHeader](#/c/SectionHeader).
- Статус коротким словом в капсуле — [Tag](#/c/Tag).

## Шкала ролей

| Роль | Размер | Когда |
|---|---|---|
| `display` | 32, шрифт заголовков, полужирный | заголовок страницы, шапка шторки, время на стене |
| `headline` | 24 | крупный заголовок блока: название встречи в «Сейчас», раздел дашборда |
| `title` | 20, полужирный | заголовок карточки или плитки: товар Ленты, задача T-411 |
| `lead` | 20 | вводный абзац, полный текст в шторке (так открывается [Excerpt](#/c/Excerpt)) |
| `body` (по умолчанию) | 16 | основной текст: строки дел, пояснения, сообщения |
| `caption` | 14 | второстепенное: дата, источник новости, «обновлено 5 мин назад» |
| `label` | 12, прописные, разрядка, серый | надпись над группой: «СКОРО», «РАСХОДЫ», «АГЕНТЫ» |

На странице обычно хватает трёх ролей: одна крупная (`display` или `headline`), `body` и `caption`. `label` — только надпись над блоком, не текст кнопки и не статус.

## Тоны и начертание

- `muted` — второстепенное и пустое: «Никто не ждёт», «На сегодня всё».
- `ok`, `warn`, `danger` — только если цвет несёт статус: «оплачено», «через 3 мин», «упал».
- `weight="medium"` или `"semibold"` — выделить часть строки (имя в «Иван ответил в MM»), не весь абзац.

## Тег и обрезка

- `as` выбирает элемент: `span` по умолчанию, `p` для абзаца, `h1`–`h4` для заголовков. Роль и тег независимы: `variant="display" as="h1"` на странице, `variant="title" as="h3"` в карточке.
- `lines={1}` — одна строка с многоточием; `2` и `3` — обрезка по строкам. Полный текст при обрезке передавайте в `title`, он покажется подсказкой при наведении.

## В киоске

Внутри `.vs-kiosk` все роли увеличиваются в 1,25 раза через `--vs-scale`. Отдельных правил у Text нет — не задавайте размеры текста на стене вручную.

## Доступность

- Заголовок страницы — `as="h1"`, разделы — `h2`–`h4` по порядку. Роль `display` без `as` остаётся `span` и в оглавлении скринридера не появится.
- Цвет тона не единственный носитель смысла: «VPN не в сети» читается и без красного.
- `label` выводится прописными через CSS; в разметке пишите обычным регистром, скринридер прочитает слово, а не буквы.

## Делай / не делай

| Делай | Не делай |
|---|---|
| `variant="caption" tone="muted"` для даты | `<span style={{ fontSize: 13, color: "#999" }}>` |
| Одна крупная роль на блок | `headline` и `title` в соседних строках |
| `lines={2}` и полный текст в `title` | Обрезать строку по символам в коде |
| `variant="label"` над группой «Скоро» | `label` для текста кнопки или статуса |
| Менять шкалу через `--vs-text-*` в дизайн-системе | Перебивать `.vs-text--body` на сайте |
