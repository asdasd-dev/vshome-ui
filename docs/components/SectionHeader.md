# SectionHeader

Заголовок раздела внутри страницы: мелкий капс серым, счётчик рядом, подпись или кнопка справа.

## Когда применять

- Над группой карточек или списком на сайте: «Ждут ревью · 3», «Сервисы», «Inbox».
- Когда справа нужен период или ссылка «Все»: «Расход — за 7 дней».

## Когда не применять

- Заголовок всей страницы — [PageHeader](#/c/PageHeader).
- Подпись блока на стене или «Столе» — `label` у [Tile](#/c/Tile).
- Заголовок в тексте статьи — `h2`/`h3` внутри [Prose](#/c/Prose).
- Подпись группы строк списка — `label` у [List](#/c/List).

## Анатомия

1. Заголовок `title` — тег из `as` (`h2` по умолчанию, `h3`, `h4`), капс, `--vs-text-xs`, серый.
2. Счётчик `count` — серый [Badge](#/c/Badge) сразу после заголовка; `0` тоже показывается.
3. `aside` — справа, серым, не переносится: период, «Все», маленькая кнопка.

## Доступность

- `as` выбирайте по уровню в документе: под `PageHeader` (`h1`) — `h2`, внутри раздела — `h3`.
- Капс задан стилем, в разметке текст обычный: скринридер читает его как слово, а не по буквам.

## Делай / не делай

| Делай | Не делай |
|---|---|
| «Ждут ревью» + `count={3}` | «Ждут ревью (3)» строкой |
| Писать заголовок обычным регистром | Набирать «СЕРВИСЫ» капсом в коде |
| Правильный уровень через `as` | Все разделы `h2`, вложенные тоже |
| Вид менять через токены дизайн-системы | Писать `.vs-section-header__title { font-size: … }` на сайте |
