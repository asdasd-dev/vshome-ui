# Tag

Короткая метка в капсуле: статус, категория или признак объекта. Не нажимается — только показывает.

## Когда применять

- Статус задачи на доске: «inbox», «doing», «review».
- Признак товара в Ленте: «−25%», «акция», «без сахара».
- Категория новости или источник: «Работа», «Домлаб», «РБК».
- Состояние сервиса на дашборде словом: «в сети», «упал».

## Когда не применять

- Метка, которую нажимают для фильтра или выбора, — [Chip](#/c/Chip).
- Счётчик непрочитанного — [Badge](#/c/Badge).
- Только цвет состояния без слова — [StatusDot](#/c/Legend).
- Предупреждение с объяснением — [Banner](#/c/Banner).

## Анатомия

1. Капсула: фон мягкого оттенка тона (`soft`) или рамка цвета текста (`outline`).
2. Иконка слева (`icon`), размером с текст.
3. Подпись — одно-два слова, в одну строку, не переносится; длинный текст обрезается многоточием по ширине контейнера.

## Варианты

| Вариант | Когда |
|---|---|
| `soft` (по умолчанию) | обычная метка, читается как часть строки |
| `outline` | метка рядом с другими цветными элементами, где заливка спорит с ними |

## Тоны

| Тон | Когда |
|---|---|
| `default` (по умолчанию) | нейтральная метка: категория, источник |
| `accent` | текущее, выбранное: «doing» |
| `ok` | готово, в норме: «в сети», «оплачено» |
| `warn` | требует внимания: «review», «истекает» |
| `danger` | сбой, просрочка: «упал», «просрочено» |
| `muted` | неактуальное: «архив», «отложено» |
| `violet`, `pink`, `gold` | категории без статусного смысла: домены задач, разделы Ленты |

## Размеры

- `md` (по умолчанию) — 12 px, в карточках и строках.
- `sm` — 11 px, в плотных местах: строки таблиц, мета строки списка.

## В киоске

Отступы и текст умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`), отдельных правил нет.

## Доступность

- Смысл несёт слово, цвет его только дублирует: «упал» понятен и без красного.
- Иконка внутри без подписи для скринридера — она декоративная, слово рядом обязательно.

## Делай / не делай

| Делай | Не делай |
|---|---|
| «doing», «−25%» — одно-два слова | Предложение в капсуле |
| Статусные тоны по смыслу статуса | `danger` для категории «Работа» |
| `violet`/`pink`/`gold` для категорий | Пять статусных цветов в одной строке |
| Фильтр по меткам — [Chip](#/c/Chip) | `onClick` на обёртке вокруг Tag |
| Менять вид через `--vs-tag-*` в дизайн-системе | Перебивать `.vs-tag` на сайте |
