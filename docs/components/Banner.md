# Banner

Сообщение о состоянии страницы или блока: данные устарели, сервис не отвечает, действие нужно сейчас. Иконка задаётся тоном, текст объясняет, что случилось, `action` — что с этим сделать.

## Когда применять

- Строка под заголовком плитки: «Данные за 10 мин назад», «2 в MM».
- Блок с объяснением (`variant="box"`): «VPN не в сети с 08:14 — проверь роутер», «Лента не обновлялась сутки».
- Состояние, которое держится, пока не изменится причина.

## Когда не применять

- Подтверждение действия, которое исчезнет само: «Сохранено» — [Toast](#/c/Toast).
- Статус объекта одним словом — [Tag](#/c/Tag).
- Пустой блок без данных — [EmptyState](#/c/EmptyState).
- Ошибка поля формы — подсказка [Field](#/c/Field).

## Анатомия

1. Иконка по тону: `alert` у `warn`, `danger`, `muted`; `info` у `accent`; `check` у `ok`.
2. Заголовок (`title`) — полужирный, над текстом; необязателен.
3. Текст (`children`) — что случилось и что делать.
4. Действие (`action`) — справа, обычно [Button](#/c/Button) `size="sm"` или [Link](#/c/Link).

## Варианты

| Вариант | Когда |
|---|---|
| `inline` (по умолчанию) | строка полужирного цветного текста без фона: внутри плитки, под заголовком |
| `box` | блок с мягким фоном тона и отступами: над содержимым страницы, в шторке |

## Тоны

| Тон | Когда |
|---|---|
| `warn` (по умолчанию) | нужно внимание: данные устарели, срок близко |
| `danger` | сбой: сервис не отвечает, оплата не прошла |
| `accent` | сведения: новая версия, режим «Сон» включён |
| `ok` | проблема решена, всё в норме после сбоя |
| `muted` | справочное: «показаны данные из кэша» |

## Состояния

- `truncate` — текст в одну строку с многоточием; для `inline` в узких местах (шапка плитки).
- Без `title` текст идёт сразу за иконкой.

## В киоске

Отступы, иконка и текст умножаются на `--vs-scale` (1,25 внутри `.vs-kiosk`), своих правил нет.

## Доступность

- Баннер — `role="status"`: скринридер зачитает появление без перевода фокуса. У `tone="danger"` — `role="alert"`, скринридер прерывает текущее чтение.
- Смысл несёт текст, а не цвет и иконка: «не в сети», а не просто красный треугольник.
- Действие — настоящая кнопка или ссылка, а не нажимаемый баннер целиком.

## Делай / не делай

| Делай | Не делай |
|---|---|
| «VPN не в сети с 08:14» | «Ошибка» |
| Одно действие в `action`: «Повторить» | Три кнопки в баннере |
| `box` над страницей, `inline` в плитке | `box` в каждой строке списка |
| Убирать баннер, когда причина ушла | Показывать «всё хорошо» постоянно |
| Менять фон через `--vs-banner-soft` и тоны в дизайн-системе | Перебивать `.vs-banner` на сайте |
