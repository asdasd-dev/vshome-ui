# Link

Текстовая ссылка внутри строки или подписи: перейти на другую страницу, открыть внешний адрес. С `href` рисуется `<a>`, без `href` — кнопка, похожая на ссылку, для мелкого действия в тексте.

## Когда применять

- Переход по адресу: «Открыть доску», «Все товары в Ленте», ссылка на PR из карточки задачи.
- Внешний сайт в новой вкладке (`external`): тред в Mattermost, страница товара в магазине.
- Мелкое действие посреди текста без `href`: «показать ещё», «сбросить фильтры» под пустым списком.

## Когда не применять

- Действие с последствиями («Сохранить», «Удалить») — [Button](#/c/Button).
- Целая плитка или карточка ведёт на страницу — `Card href` или [Tile](#/c/Tile).
- Фильтр или вкладка, которая держит выбранное состояние — [Chip](#/c/Chip) с `href` или [Tabs](#/c/Tabs).
- Иконка без текста — [IconButton](#/c/IconButton).

## Анатомия

1. Текст ссылки — наследует шрифт и размер окружения.
2. Иконка `external` после текста — только при `external` и заданном `href`.

## Варианты

| `tone` | Когда |
|---|---|
| `accent` (по умолчанию) | обычная ссылка |
| `muted` | второстепенная ссылка в подписи, метаданных, подвале |
| `danger` | действие-ссылка, которое удаляет или отменяет («убрать из списка») |

Подчёркивание: `underline="hover"` (по умолчанию) — только при наведении; `underline="always"` — всегда, для ссылок посреди сплошного текста, где цвета мало.

## Состояния

- Наведение — подчёркивание у `underline="hover"`, только на устройствах с указателем.
- Фокус — кольцо `--vs-focus-ring` со скруглением.
- `disabled` — серый текст без подчёркивания, курсор «нельзя»; рисуется кнопкой без перехода, даже с `href`.
- `onClick` получает событие клика. Внутри карточки-ссылки (`Card href`) вызовите `e.preventDefault()`: сработает действие ссылки, а карточка не перейдёт по своему адресу. С `href` то же отменяет переход самой ссылки.

## Доступность

- С `href` — настоящая ссылка: открывается в новой вкладке, копируется, читается как «ссылка».
- Без `href` — `<button type="button">`: скринридер слышит «кнопка». Не используйте её для перехода.
- `external` добавляет `target="_blank"` и `rel="noopener noreferrer"`; иконка подсказывает, что откроется новая вкладка.
- Текст ссылки понятен сам по себе: «Тред в Mattermost», а не «тут».

## Делай / не делай

| Делай | Не делай |
|---|---|
| `href` для перехода | `onClick={() => location.href = …}` без `href` |
| `external` для чужих сайтов | `external` для страниц того же сайта |
| «Все задачи в Doing» | «Подробнее», «здесь», «ссылка» |
| `underline="always"` внутри абзаца | Ссылка без подчёркивания в сером тексте |
| Новый `tone` — в дизайн-системе | `.my-page .vs-link { color: … }` на сайте |
