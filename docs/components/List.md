# List

Список однотипных строк с разделителями: дела на стене, агенты в «Столе», новости, сообщения Mattermost. `List` задаёт подпись, предел и пустое состояние, `ListRow` — одну строку.

## Когда применять

- Короткий список, где у строки есть название и, по желанию, пояснение, число справа или метка слева: дела на сегодня, агенты, ждущие ответа, новости с источником.
- Список, который не помещается целиком: `max` показывает первые строки и «ещё N».
- Список в плитке киоска фиксированной высоты: `fit` показывает столько целых строк, сколько влезает; «ещё N» под ними — только с `onMore`.
- Строка, которая открывает подробности по касанию: `onClick` у `ListRow`.
- Строка, которая ведёт на страницу: `href` у `ListRow` — товар Ленты, задача на доске.
- Строка с картинкой слева: [Artwork](#/c/Artwork) в `lead` и `align="center"`.

## Когда не применять

- Данные в нескольких колонках, которые сравнивают между собой, — [Table](#/c/Table).
- Пары «название — значение» — [KeyValue](#/c/KeyValue).
- Строки с переключателями и ползунками — [ControlList](#/c/ControlList).
- Переход на другую страницу из блока с картинкой и текстом в несколько строк — [Card](#/c/Card) с `href`; ссылка внутри текста — [Link](#/c/Link).
- Длинный текст из markdown со списком внутри — [Prose](#/c/Prose).

## Анатомия

1. Подпись списка (`label`) — роль `label`: прописные, серым.
2. Слева в строке (`lead`) — время, номер, иконка, картинка; серым, моноширинные цифры.
3. Название (`title`) — 16 px, одна строка с многоточием или две (`titleLines={2}`).
4. Пояснение (`sub`) — 14 px под названием, 1–3 строки (`subLines`), серое или `subTone="warn"`.
5. Справа (`meta`) — время, сумма, [Tag](#/c/Tag); не сжимается.
6. «ещё N» под списком при `max`; при `fit` — только с `onMore`, тогда нажимается.

## Тоны строки

| Тон | Что меняется |
|---|---|
| `default` (по умолчанию) | — |
| `warn` | `meta` оранжевым: срок близко |
| `danger` | `meta` красным: просрочено |
| `muted` | название серым: сделанное, неактуальное |

## Выравнивание

- `align="baseline"` (по умолчанию) — `lead`, название и `meta` по первой строке текста: время и сумма стоят вровень с названием.
- `align="center"` — по центру строки: картинка в `lead` выше строки текста, и иначе название прилипает к её верху.

## Колонка времени

`List lead="time"` — колонка `lead` одной ширины у всех строк (`--vs-space-12`), текст в ней мелкий (`--vs-text-sm`) и приглушённый, цифры табличные: названия начинаются с одной линии, как в расписании на «Столе». Вместо времени в колонке может стоять значок: [Icon](#/c/Icon) `task` у дела из списка задач, `calendar` у события на весь день.

## Новое в 0.58

- `List fit` без `onMore` — только целые строки, строки «ещё N» нет, место под неё не оставляется. С `onMore` — как в 0.57: нажимаемое «ещё N».

## Новое в 0.57

- `List fit` — строк столько, сколько целиком помещается по высоте, остальное — «ещё N»: в плитке стены ни одна строка не режется пополам и не уходит в затемнение. Список растягивается на свободное место родителя-flex (тело [Tile](#/c/Tile)); `Tile` с ним — без `scroll`.
- `List onMore` — «ещё N» нажимается.

## Новое в 0.56

- В киоске (`.vs-kiosk`) название и подпись строки переносятся по словам и по слогам (`--vs-list-hyphens: auto`, язык берётся из `lang` страницы), по символам — только слово длиннее строки: ссылка, ключ (`--vs-list-wrap: anywhere`). Заменяет перенос по символам из 0.41.

## Новое в 0.41

- В киоске (`.vs-kiosk`) название и подпись строки переносятся по символам (`--vs-list-break: break-all`): строка заполняется до конца, многоточие на последней строке тоже по символу. Вне киоска перенос по словам, как раньше.
- `List lead="time"` — отступ между колонкой и названием `--vs-space-2` вместо `--vs-space-3`: мелкое время стоит ближе к крупному названию.

## Новое в 0.38

- `List lead="time"` — ровная колонка времени мелким кеглем.

## Список-навигация

- `List divided={false}` — без разделителей между строками, у строк поля по бокам: список разделов или категорий в боковой панели.
- `ListRow selected` — выбранная строка: мягкая акцентная подложка `--vs-accent-tint`, название и `meta` акцентом и полужирным, `aria-current="true"` у строки. Число справа — в `meta`.

## Состояния

- Пустой список: без строк рендерится `empty`, а если его нет — ничего.
- `max` — показываются первые `max` строк, ниже «ещё N»; «ещё N» не нажимается без `onMore`.
- `fit` — строк столько, сколько целиком влезает по высоте; «ещё N» — только с `onMore`. Пересчёт при смене строк и размера.
- `onMore` — «ещё N» становится кнопкой акцентным цветом: открыть полный список (доску, вкладку).
- Строка с `onClick` становится кнопкой: шеврон `›` справа (до `action`), затемнение при нажатии и наведении, кольцо фокуса `--vs-focus-ring`. Строка без `onClick` и `href` шеврона не имеет — по нему видно, что откроется.
- Строка с `href` становится ссылкой `a` с тем же шевроном и подсветкой. `onClick` вместе с `href` вызывается до перехода — например, для счётчика открытий.

## В киоске

Внутри `.vs-kiosk` всё умножается на `--vs-scale` (1,25), а название двухстрочной строки (с `sub`) становится средним по насыщенности через `--vs-list-name-weight`. На сайте этого не повторяйте вручную.

## Доступность

- Список размечен `ul`/`li`, скринридер называет число строк.
- Нажимаемая строка — `button`, работает с клавиатуры.
- Строка с `href` — настоящая ссылка: открывается в новой вкладке по Cmd/Ctrl-клику или колёсиком, адрес копируется.
- `label` выводится абзацем над списком и не связан с ним атрибутом; если на странице несколько списков, озаглавьте раздел через [SectionHeader](#/c/SectionHeader).

## Делай / не делай

| Делай | Не делай |
|---|---|
| `max` и «ещё N» или `fit` на стене | Прокручивать стену вниз ради списка |
| `fit` в `Tile` без `scroll` | `fit` вместе с `Tile scroll`: список растянется по содержимому и не обрежется |
| `empty="Никто не ждёт"` | Пустой блок с одной подписью |
| Время в `lead`, сумма в `meta` | Склеивать «14:00 Синк — 30 мин» в `title` |
| `tone="muted"` для сделанного | Зачёркивать текст своим стилем |
| `href` у строки, которая ведёт на страницу | `onClick` с `location.href = …` |
| Менять вес названия через `--vs-list-name-weight` в дизайн-системе | Перебивать `.vs-list-row__title` на сайте |

## Новое в 0.44

- `lead="icon"` — колонка слева по ширине значка (дела, статусы) с тем же уменьшенным отступом, что у `lead="time"`. Для списка, где слева только значки, — чтобы название не отъезжало на ширину колонки времени.

## Новое в 0.45

- В строке с подписью колонка слева (время, дата) стоит на одной базовой линии с названием; `meta` справа по-прежнему сверху. В `lead="icon"` значок по центру первой строки названия.

## Новое в 0.49

- `ListRow action` — кнопка справа от строки, вне её кнопки или ссылки: нажатие не открывает строку. Обычно [IconButton](#/c/IconButton) `size="sm"`, например «Прочитано» у треда Mattermost на «Столе».
