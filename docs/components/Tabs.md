# Tabs

Вкладки: переключают разделы одной страницы или ведут по адресам. Линия снизу у текущей; на телефоне вариант `bottom` превращается в нижнюю панель навигации.

## Когда применять

- Разделы одной страницы: статусы задач на доске «Inbox · Doing · Review · Done».
- Навигация между страницами сайта на одном уровне: «Лента · Источники · Сохранённое» — с `href` у пунктов.
- Нижняя панель приложения на телефоне: `variant="bottom"` с иконками.

## Когда не применять

- Выбор режима или фильтра, который меняет вид тех же данных («Доска / Бэклог», «7 дней / 3 дня») — [Segment](#/c/Segment).
- Два-три фильтра, которые можно включать вместе — [Chip](#/c/Chip).
- Свернуть второстепенное — [Disclosure](#/c/Disclosure).

## Анатомия

1. Ряд вкладок с линией `--vs-line` снизу; не помещаются — прокручиваются вбок без полосы.
2. Вкладка — `icon`, `label`, `count`.
3. Счётчик `count` — [Badge](#/c/Badge): синий у текущей, серый у остальных.
4. Индикатор — линия `--vs-accent` под текущей.

## Варианты

| `variant` | Когда |
|---|---|
| `underline` (по умолчанию) | вкладки в шапке или над разделом |
| `bottom` | на ширине до 760px — панель, прибитая к низу экрана, вкладки делят ширину, иконка над подписью, текущая синяя; шире 760px выглядит как `underline` |

## Состояния

- Кнопки или ссылки: если хоть у одного пункта есть `href`, все пункты — ссылки в `nav`, текущая отмечена `aria-current="page"`. Иначе — кнопки `role="tab"` с `aria-selected`.
- `value` — текущая вкладка; `onChange` вызывается при выборе, у ссылок — до перехода.
- Наведение — текст темнеет до `--vs-ink`.
- Фокус — кольцо `--vs-focus-ring`.

## Доступность

- `label` обязателен: имя группы вкладок для скринридера («Статус задач»).
- Вкладки-кнопки не управляют панелями (`aria-controls` нет): содержимое раздела страница показывает сама.

## Делай / не делай

| Делай | Не делай |
|---|---|
| 2–5 вкладок с короткими подписями | Десять вкладок, половина за краем |
| `href` у пунктов, если у раздела свой адрес | Менять адрес вручную в `onChange` |
| `count` для числа задач в статусе | Вписывать число в `label` текстом |
| `bottom` — одна панель на приложение | Две нижние панели на одном экране |
| Вид менять через токены дизайн-системы | Писать `.vs-tabs__item { color: … }` на сайте |
