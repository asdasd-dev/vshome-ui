# Цвет

Все цвета — семантические токены. Компонент и сайт пишут не «синий», а «акцент»; конкретное значение зависит от темы.

## Нейтральные

| Токен | Назначение |
|---|---|
| `--vs-bg` (`--vs-surface-0`) | фон страницы |
| `--vs-panel` (`--vs-surface-1`) | плитки, карточки, шторки |
| `--vs-surface-2` | поле внутри панели: кнопки киоска, дорожки, подложки |
| `--vs-ink` | основной текст |
| `--vs-muted` | второстепенный текст, подписи, иконки состояния |
| `--vs-line` | разделители и рамки |

## Акцент и состояния

| Токен | Значит | Где |
|---|---|---|
| `--vs-accent` | действие, выбор, ссылка | `primary`-кнопка, выбранная вкладка, фокус |
| `--vs-ok` | хорошо, готово, в норме | успешный тост, «работает» |
| `--vs-warn` | требует внимания скоро | встреча через 5 минут, ждущий агент |
| `--vs-danger` | ошибка, просрочено, разрушающее действие | «Мак недоступен», «Удалить» |
| `--vs-lamp` | горит свет | точка-лампа у комнат |
| `--vs-on-accent` | текст поверх акцента и статусов | подпись на `primary`, число в `Badge` |

## Мягкие варианты

Для фонов и подложек — не исходный цвет, а смесь:

| Токен | Смесь |
|---|---|
| `--vs-ok-soft`, `--vs-warn-soft`, `--vs-danger-soft` | 8–14% цвета на `--vs-panel` — фон плитки, баннера, карточки |
| `--vs-accent-soft` | 22% акцента на `--vs-surface-2` — нажатая кнопка |
| `--vs-accent-tint` | 14% акцента на прозрачном — подсветка пункта меню, выбранный чип |
| `--vs-accent-fill` | 35% акцента на `--vs-surface-2` — заполненная часть ползунка |
| `--vs-hover` | 6% текста на прозрачном — наведение |

## Цвета категорий

`--vs-violet`, `--vs-pink`, `--vs-gold` и их `*-soft` — для различения категорий, где статусы не подходят: магазин в Ленте, звёзды оценки, третья серия графика. Они ничего не значат сами по себе — не используйте их как «предупреждение» или «успех».

`--vs-calendar-orange`, `--vs-calendar-purple`, `--vs-calendar-blue`, `--vs-calendar-green` — цвета календарей, один в один как в Apple Календаре (Личный, Полина, Работа, Общий), одинаковые в светлой и тёмной теме. Только для пометки, из какого календаря событие.

## Правила

- Один акцент на экран. Если всё синее, ничего не выделено.
- Статусный цвет — только для статуса. Красный заголовок «для красоты» читается как ошибка.
- Цвет не единственный носитель смысла: рядом всегда текст или иконка («просрочено 3 дня», ⚠).
- Никаких hex, `rgb()` и именованных цветов в стилях компонентов и сайтов — тест это ловит. Нужен новый цвет — новый токен в обеих темах.
