# Иконки

## Набор

Иконки — только из набора [Icon](#/c/Icon) (`ICON_NAMES`): монохромные контуры 24 × 24, цвет — `currentColor`. Погода (`weather-*`), стрелки, `close`, `check`, `search`, `plus` и другие — пути из Material Design Icons (Apache-2.0), источник указан в README.

## Размеры

`sm` (16) — внутри кнопок и полей, `md` (20) — самостоятельные, `lg` (24) — в пустых состояниях, `em` — по размеру окружающего текста (погода рядом с температурой). В киоске × 1,25.

## Подпись

- Иконка рядом с текстом, который говорит то же самое, — декоративная (`aria-hidden`, по умолчанию).
- Иконка вместо слова — с `label` (`role="img"`): погода «облачно».
- Кнопка из одной иконки — [IconButton](#/c/IconButton) с обязательным `label`.

## Нельзя

- Текстовые символы как иконки: `✕ ✓ ▾ ▸ ×` — тест это ловит.
- Эмодзи как элементы управления. Эмодзи допустимы в данных пользователя (приоритет задачи, заглушка `Artwork`).
- Свои `<svg>` на сайте. Нужна иконка — добавьте путь в `src/components/icons.ts`, в тест набора и в каталог.

## Как добавить иконку

1. Найдите подходящую в `@mdi/js` (тот же стиль), возьмите `path`.
2. Добавьте в `ICONS` с именем по смыслу (`arrow-left`, а не `mdiArrowLeft`).
3. Обновите тест набора иконок — он перечисляет имена явно.
