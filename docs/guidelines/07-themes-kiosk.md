# Темы и киоск

## Светлая и тёмная

- Тема одна на страницу — атрибут `data-theme="light"` или `data-theme="dark"` на `<html>`. Там всегда итоговая тема: выбор «Как в системе» превращается в `light` или `dark` и меняется вместе с системой.
- Атрибут ставит скрипт, который `vshomeBuild` вставляет первым в `<head>`, ещё до отрисовки; дальше его ведёт `useTheme`. Без `singleFile` скрипт лежит отдельным файлом, потому что CSP сайтов запрещает инлайн-скрипты.
- Сайт с переключателем передаёт одинаковые `{ key, fallback }` в `vshomeBuild({ theme })` и `useTheme()`; без переключателя хватает умолчаний (`vs-theme`, «как в системе»).
- Киоск и всегда тёмный дашборд ставят `data-theme` сами и собираются с `theme: false`. Так стена днём светлая, а вечером тёмная; киоск, который следует за системой, берёт её из `useSystemTheme()`.
- Стили сайта под тёмную тему — только `:root[data-theme="dark"] …`; в коде — `useTheme().resolved`, `choice` нужен только переключателю.
- Нельзя: `prefers-color-scheme` в стилях и коде сайта, свои атрибуты темы (`data-color-scheme`, `data-<что-то>-theme`), `data-theme` не на `<html>`. Сборка `vshomeBuild` на таком падает и называет строку.
- Каждый цветовой токен определён в обеих темах. Тёмные значения записаны дважды: для `data-theme="dark"` и для системной тёмной, пока скрипт ещё не поставил атрибут; тест сверяет, что копии одинаковые.
- Своих тем на сайтах нет: токены не переопределяются под «свою» тёмную тему.

## Киоск

Класс `.vs-kiosk` на корне страницы планшета (стена, «Стол») включает режим киоска:

- `--vs-scale: 1.25` — все шкалы (отступы, текст) крупнее;
- кнопки — капсулы без рамки на `--vs-surface-2`, высота 44 × масштаб;
- шторки — крупные, без рамок, скругление `xl`;
- заголовки строк списка — средний вес.

`Sheet` и всплывающие окна рендерятся вне корня — передайте им `className="vs-kiosk"`; `Excerpt` делает это сам.

## Как компонент поддерживает киоск

Компонент читает свои переменные со значениями по умолчанию, а киоск задаёт эти переменные на `.vs-kiosk`:

```css
.vs-button { min-height: var(--vs-button-h, calc(40px * var(--vs-scale, 1))); }
.vs-kiosk { --vs-button-h: calc(44px * var(--vs-scale, 1)); }
.vs-button--sm { --vs-button-h: calc(32px * var(--vs-scale, 1)); }
```

Модификатор задаёт переменную на самом элементе и поэтому побеждает киоск без повышения специфичности. Правила вида `.vs-kiosk .vs-button--x { … }` запрещены тестом.
