# Темы и киоск

## Светлая и тёмная

- По умолчанию тема — по системе (`prefers-color-scheme`).
- Принудительно — атрибут на `<html>`: `data-theme="light"` или `data-theme="dark"`. Так стена днём светлая, а вечером тёмная по времени.
- Каждый цветовой токен определён в обеих темах. Тёмные значения записаны дважды — для системной тёмной и для `data-theme="dark"`; тест сверяет, что копии одинаковые.
- Своих тем на сайтах нет: дашборд, которому нужен тёмный вид всегда, ставит `data-theme="dark"`, а не переопределяет токены.

## Киоск

Класс `.vs-kiosk` на корне страницы планшета (стена, «Стол») включает режим киоска:

- `--vs-scale: 1.25` — все шкалы (отступы, текст) крупнее;
- кнопки — капсулы без рамки на `--vs-surface-2`, высота 44 × масштаб;
- шторки — крупные, без рамок, скругление `xl`;
- заголовки строк списка — средний вес.

`Sheet` и всплывающие окна рендерятся вне корня — передайте им `className="vs-kiosk"`; `Excerpt` делает это сам.

## Как компонент поддерживает киоск

Компонент читает свои переменные со значениями по умолчанию, а киоск задаёт эти переменные на `.vs-kiosk`:

```css
.vs-button { min-height: var(--vs-button-h, calc(40px * var(--vs-scale, 1))); }
.vs-kiosk { --vs-button-h: calc(44px * var(--vs-scale, 1)); }
.vs-button--sm { --vs-button-h: calc(32px * var(--vs-scale, 1)); }
```

Модификатор задаёт переменную на самом элементе и поэтому побеждает киоск без повышения специфичности. Правила вида `.vs-kiosk .vs-button--x { … }` запрещены тестом.
