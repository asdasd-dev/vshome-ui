# О дизайн-системе

`@vshome/ui` — общая дизайн-система всех веб-интерфейсов vshome: дашборд vshome.space, стена в коридоре (Pad 6), «Стол» (Pad 7), доска задач и план обучения, Лента. В ней токены, компоненты, графики, работа с сетью и пресеты сборки и тестов.

## Что даёт

- **Один вид везде.** Цвета, шрифты, отступы и поведение одинаковы на всех сайтах и планшетах.
- **Правка в одном месте.** Изменили компонент — релиз и раскатка по сайтам происходят сами, сайты остаются зелёными или получают задачу на починку.
- **Минимум своей вёрстки на сайтах.** Сайт отвечает только за раскладку страницы и данные. Всё, что видно и нажимается, — компоненты системы.

## Как подключить

```tsx
import "@vshome/ui/fonts.css";
import { Button, Card, PageHeader } from "@vshome/ui";
import { LineChart } from "@vshome/ui/charts";
```

Пакет ставится git-зависимостью по тегу: `"@vshome/ui": "github:asdasd-dev/vshome-ui#vX.Y.Z"`. Версию в сайтах поднимает раскатка после релиза — руками не меняйте.

## Где что лежит

- Код и стили компонентов — `src/components/<Имя>.tsx` и `<Имя>.css`, токены — `src/styles/tokens.css`.
- Эти тексты — `docs/guidelines/` и `docs/components/` в репозитории `asdasd-dev/vshome-ui`.
- Каталог с примерами — `vshome.space/ui/`, исходник — `showcase/`.
