# Отступы и раскладка

## Шкала отступов

Шаг 4 пикселя: `--vs-space-0_5` (2), `1` (4), `1_5` (6), `2` (8), `3` (12), `4` (16), `5` (20), `6` (24), `8` (32), `10` (40), `12` (48). В киоске × `--vs-scale`.

| Где | Отступ |
|---|---|
| иконка ↔ подпись, бейдж ↔ текст | `1`–`1_5` |
| элементы в ряду (кнопки, чипы) | `2` |
| строки и блоки внутри плитки | `3` |
| между плитками и карточками | `4` |
| поля страницы | `4`–`5` |
| между крупными разделами | `6`–`8` |

## Скругления

`--vs-radius-xs` (4) — мелкие элементы и фокус, `sm` (8) — поля, кнопки вне киоска, `md` (12) — меню, баннеры, `lg` (16) — карточки, шторки, `xl` (24) — плитки киоска, `pill` — капсулы. Скругление вложенного элемента меньше, чем у родителя.

## Раскладка

- **Внутри компонентов и блоков** — [Cluster](#/c/Layout) (ряд), [Stack](#/c/Layout) (колонка), [Divider](#/c/Layout). Свой `display: flex` с `gap` на сайте — сигнал взять их.
- **Раскладка страницы** — сетки плиток, ширина колонок, липкие панели, позиционирование — пишется на сайте, это его ответственность. Тест сайта разрешает в его стилях только свойства раскладки.
- Зоны касания — не меньше 44 × 44 (в киоске × 1,25). Компоненты это соблюдают сами.

## Брейкпоинт

Один: **760px** — телефон. Ниже `Sheet` становится нижней шторкой, `Tabs variant="bottom"` — нижней панелью. В JS — `SHEET_MOBILE` и `useMediaQuery`. Медиазапросы не умеют читать переменные, поэтому число пишется в `@media` — это единственное место для литерала.
