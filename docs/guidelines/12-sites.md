# Правила для сайтов

Сайт отвечает за данные и раскладку страницы. Всё, что видно и нажимается, — компоненты системы.

## Можно в стилях сайта

- Корень страницы: фон, шрифт, `data-theme`.
- Раскладка: `display`, `grid-*`, `flex-*`, `gap`, `padding`, `margin`, размеры, позиционирование, `overflow`.
- Привязка к области сетки: `[data-tile="news"] { grid-area: news; }`.

## Нельзя

- Цвета, шрифты, размеры текста, рамки, тени, скругления — это вид компонента.
- Селекторы с `.vs-*`: не перебивайте компоненты. Не хватает варианта — проп или переменная в системе.
- Свои кнопки, поля, чипы, бейджи, вкладки, карточки, таблицы — если в системе есть компонент.
- Классы компонентов вручную (`<button className="vs-button vs-button--primary">`) — только сам компонент.
- Свои палитры (`--bg`, `--card`, `--accent`) поверх токенов.
- `style={{ color: … }}` и прочие инлайн-стили вида.

## Как проверяется

В каждом сайте тест-сторож читает его CSS: вне корня страницы допускаются только свойства раскладки и ни одного `.vs-*`. Стена и «Стол» уже под таким сторожем; доска, план обучения, Лента и дашборд переводятся на него.

## Если нужно то, чего нет

1. Поищите в каталоге — компонент мог называться иначе.
2. Если это вариант существующего — PR в систему с новым пропом.
3. Если новый элемент и он повторится — новый компонент по [правилам развития](#/g/11-contributing).
4. Если доменная вещь — соберите её на сайте из компонентов системы, свою вёрстку — только для раскладки.
