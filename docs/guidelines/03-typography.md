# Типографика

## Шрифты

- **Manrope** (`--vs-font`) — весь текст интерфейса.
- **Unbounded** (`--vs-font-display`) — крупные цифры и заголовки-витрины: часы, `Stat`, `display`.
- Подключение — `import "@vshome/ui/fonts.css"`; шрифты лежат в пакете, без внешних CDN.

## Шкала

| Токен | Размер / интерлиньяж | Роль `Text` |
|---|---|---|
| `--vs-text-4xl` | 72 / 76 | часы `Clock xl`, `Stat xl` |
| `--vs-text-3xl` | 48 / 52 | часы шапки стены |
| `--vs-text-2xl` | 32 / 40 | `display` |
| `--vs-text-xl` | 24 / 32 | `headline` |
| `--vs-text-lg` | 20 / 28 | `title`, `lead` |
| `--vs-text-md` | 16 / 24 | `body` |
| `--vs-text-sm` | 14 / 20 | `caption` |
| `--vs-text-xs` | 12 / 16 | `label` |
| `--vs-text-2xs` | 11 / 14 | подписи осей, `Badge` |

В киоске вся шкала умножается на `--vs-scale` (1,25).

## Роли вместо размеров

Текст на сайте — только через [Text](#/c/Text) с ролью: `display`, `headline`, `title`, `lead`, `body`, `caption`, `label`. Роль задаёт размер, интерлиньяж и вес вместе. `font-size` и `font-weight` в стилях сайта запрещены тестом.

## Вес

`--vs-weight-regular` (400) — текст, `medium` (500) — заголовки строк и кнопки в киоске, `semibold` (600) — заголовки, акцентные числа, `label`. `bold` (700) — не используем в интерфейсе.

## Правила

- Цифры, которые сравнивают в столбик или которые меняются (время, суммы), — `font-variant-numeric: tabular-nums` (уже есть в `Stat`, `Clock`, `Table`).
- Одна строка — `Text lines={1}` с многоточием, не обрезка контейнером.
- Капсом — только роль `label` и `SectionHeader`: короткие подписи групп, 1–3 слова.
- Длинный текст (описание встречи, гайдлайн) — [Prose](#/c/Prose) или [Excerpt](#/c/Excerpt), ширина строки до 72 знаков.
