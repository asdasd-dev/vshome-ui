# Паттерны

Готовые решения типовых задач. Если ваш случай здесь есть — делайте так; если нет и он повторится — добавьте паттерн.

## Страница сайта

```
PageHeader (sticky, title, sub, actions)
  └ Tabs (разделы)                     ← children шапки
main: сетка страницы (CSS сайта)
  └ Card / SectionHeader + List / Table / KeyValue
```

- Одна `PageHeader` на страницу, разделы — `Tabs`. На телефоне разделы приложения — `Tabs variant="bottom"`.
- Сетка карточек — CSS сайта (`grid-template-columns`), внутри карточки — `Stack`/`Cluster`.

## Панель киоска

```
.vs-kiosk корень
  Cluster as="header" (часы Clock, Stat погоды, статус, Segment)
  сетка плиток (CSS сайта)
    Tile label aside scroll
```

- Плитка — `Tile`, а не `Card`: подпись капсом, `aside` справа, `scroll` с затуханием.
- Приглушённые данные (источник не на связи) — `Tile dimmed`.

## Списки

- Однородные строки с заголовком, подписью и временем — `List` + `ListRow`.
- Группы — несколько `List label="…"` подряд.
- Сравнение по колонкам — `Table`; пары «подпись — значение» — `KeyValue`.

## Формы

- Поле — `TextField`/`TextArea` с `label`; ошибка — `error`, подсказка — `hint`.
- Варианты: 2–5 взаимоисключающих — `RadioGroup` или `Segment`; много — `Select`; фильтры — `ChipGroup`.
- Главное действие — одна `Button variant="primary"`; в шторке — в `footer`.

## Обратная связь

| Ситуация | Компонент |
|---|---|
| действие выполнено | `useToast` — «T-121: всё смёржено» |
| идёт загрузка | `Spinner` или `Button loading` |
| что-то не так на экране | `Banner` (в строке) или `Banner variant="box"` с действием |
| данных нет | `EmptyState` или `empty` у `List`/`Table` |
| нужно подтверждение | `Sheet` с `footer`: действие и «Отмена» |

## Раскрытие

- Длинный текст в плитке — `Excerpt` (касание — полный текст в шторке).
- Необязательные детали — `Disclosure`.
- Действия над элементом — `ContextMenu` (правый клик / долгое нажатие) и, если действие главное, видимая кнопка.

## Навигация назад

`Link` с `arrow-left`: «← К списку». Не кнопка «Назад» в шапке, если работает системный жест — `useAndroidBack` уже закрывает шторки.
