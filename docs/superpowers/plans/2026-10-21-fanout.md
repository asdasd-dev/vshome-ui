# T-100: ускорение fanout

Цель: независимые сайты обновляются двумя потоками, мёрж проходит через общий клиент с проверкой box/verify и межпроцессным замком.

Ограничения: не менять retry установки и дедупликацию задач; красный сайт не блокирует зелёные; итоговая сводка сохраняет порядок consumers.json; не запускать настоящий релиз UI ради проверки.

1. RED: два сайта могут выполнять независимые проверки, третий ждёт; неверный URL созданного PR не приводит к мёржу; мёрж использует scripts/merge-pr.mjs.
2. GREEN: пул из двух rollOne; номер PR из результата gh pr create; вызов штатной merge-команды.
3. Полный npm test, typecheck и build; одно ревью всей ветки; PR и мёрж.

Ruling: fanout сохраняет локальные test/build до PR для неприсоединённых к CI репозиториев. У personalai пока возможен повторный прогон; убирать его только вместе с подключением остальных check.sh, не по отсутствию локального файла в тестовом worktree.
