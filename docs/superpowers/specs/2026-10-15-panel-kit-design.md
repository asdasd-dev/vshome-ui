# @vshome/ui v0.5: шкалы, шрифты, панельные компоненты; «Стол» на системе (T-338)

Дизайн-ревью «Стола» (Pad 7, 2026-10-15): экран собран мимо дизайн-системы — свои шрифты (SF/Roboto), палитра iOS (`#000`, `#1c1c1e`, `#ff9f0a`, `#30d158`), отступы 14/16/18/20/22/24, скругления 14 и 30, самодельные переключатель, кнопка и иконки. Причина не только в «Столе»: в `@vshome/ui` нет шкал и компонентов для экранов-панелей, а объявленные шрифты Manrope и Unbounded нигде не загружаются — все потребители (personalai, lenta-tracker, monitoring) рисуют системным шрифтом.

Правило после этой работы: в потребителях нет собственных значений цвета, отступа, размера текста, скругления и своих SVG-иконок — только токены и компоненты `@vshome/ui`. Чего не хватает — добавляется в систему, не в потребителя.

## Часть 1. `vshome-ui` v0.5.0

### Токены (`src/styles/tokens.css`)
- Отступы, шаг 4 px: `--vs-space-1` 4px, `-2` 8px, `-3` 12px, `-4` 16px, `-5` 20px, `-6` 24px, `-8` 32px, `-10` 40px, `-12` 48px; полушаги для мелких элементов (зазор иконка–текст, отступ тега): `--vs-space-0_5` 2px, `--vs-space-1_5` 6px.
- Текст (размер / межстрочный): `--vs-text-xs` 12/16, `-sm` 14/20, `-md` 16/24, `-lg` 20/28, `-xl` 24/32, `-2xl` 32/40, `-3xl` 48/52, `-4xl` 72/76; переменные `--vs-text-*` и `--vs-leading-*`. Веса: `--vs-weight-regular` 400, `-medium` 500, `-semibold` 600, `-bold` 700.
- Скругления — фиксированный набор по типу элемента: `--vs-radius-xs` 4px (теги), `--vs-radius-sm` 8px (поля, кнопки внутри плиток), `--vs-radius-md` 12px (кнопки, обложки), `--vs-radius-lg` 16px (карточки), `--vs-radius-xl` 24px (большие плитки), `--vs-radius-pill` 999px. `--vs-radius` остаётся псевдонимом `--vs-radius-md` (было 10px). Вложенный элемент скругляется на ступень меньше родителя.
- Поверхности: `--vs-surface-0` = `--vs-bg`, `--vs-surface-1` = `--vs-panel`, `--vs-surface-2` (на ступень светлее панели в тёмной теме, темнее — в светлой) для вложенных элементов и кнопок-иконок.
- Статусы: `--vs-ok` (зелёный), `--vs-warn` (есть), `--vs-danger` (есть) и мягкие фоны `--vs-ok-soft`, `--vs-warn-soft`, `--vs-danger-soft` (12% цвета на поверхности).
- Режим плотности «киоск» — класс `.vs-kiosk` на корне страницы: умножает шкалы отступов и текста на `--vs-scale` (1.25) — для экранов, на которые смотрят с метра. Компоненты используют только токены, поэтому масштабируются сами.

### Шрифты
Manrope и Unbounded — вариативные (`@fontsource-variable`, только кириллица и латиница), отдельным файлом `@vshome/ui/fonts.css` (woff2 встроены как data:, ~160 КБ, без внешних запросов). Подключают только те, кому нужны шрифты системы (первый — «Стол»): в `style.css` они не входят, чтобы страницы со своим шрифтом не платили за них. `--vs-font` и `--vs-font-display` не меняются; `base.css`: `body { font-family: var(--vs-font); }`.

### Компоненты (`src/components`, экспорт из `index.ts`, примеры в `showcase`)
- `Tile` — плитка-поверхность: `label?` (подпись капсом, `--vs-text-xs`, `--vs-muted`), `tone?: "default" | "warn" | "danger"` (фон `*-soft`), `children`, `footer?` (прижат книзу), `onClick?` (тогда кнопка с фокусом). Отступ `--vs-space-5`, скругление `--vs-radius-xl`, фон `--vs-surface-1`.
- `Stat` — крупное значение с подписью: `value`, `unit?`, `caption?`, `tone?: "default" | "muted" | "warn" | "danger" | "ok"`, `size?: "md" | "lg" | "xl"` (`--vs-text-2xl/3xl/4xl`, шрифт display, табличные цифры).
- `ListRow` — строка списка: `title`, `meta?` (справа, muted, табличные цифры), `tone?`, `onClick?`; однострочная с многоточием; разделитель `--vs-line` между строками в `List`.
- `List` — обёртка с разделителями, `empty?` (текст, когда строк нет), `max?` + подпись «ещё N».
- `Icon` — `name`, `size?: "sm" | "md" | "lg"` (16/20/24 × scale), `currentColor`. Набор: `play`, `pause`, `prev`, `next`, `check`, `alert`, `clock`, `external`, `chevron-right`, `dot`. Пути — в одном файле `icons.ts`, без внешних библиотек.
- `IconButton` — круглая кнопка с `Icon`: `icon`, `label` (aria-label, обязателен), `size?`, `variant?: "plain" | "primary"`; минимальная зона нажатия 44px × scale.
- `Banner` — однострочное сообщение: `tone`, `children`; без фона, иконка `alert` + текст, для статуса в шапке.
- Существующие `Segment` и `Button` не меняются по API; цвета/отступы переводятся на новые токены (вид остаётся прежним).

### Проверка
- vitest: каждый компонент — роль/aria, тоны дают классы, `List` с `max` пишет «ещё N», `IconButton` без `label` — ошибка типов (`@ts-expect-error` в тесте), `Icon` неизвестного имени — ошибка типов.
- тест токенов: все `--vs-space-*`, `--vs-text-*`, `--vs-radius-*`, `--vs-surface-*`, `--vs-*-soft` определены в светлой и тёмной теме; `.vs-kiosk` задаёт `--vs-scale`.
- тест шрифтов: `styles.css` импортирует `@fontsource/manrope` и `@fontsource/unbounded`.
- витрина (`showcase`) — раздел «Панели» со всеми новыми компонентами в обычном и `.vs-kiosk`.
- Релиз — обычный: `deploy.sh` (тесты, typecheck, сборка, витрина) → тег `v0.5.0` → `fanout.mjs` открывает PR в personalai, lenta-tracker, monitoring. Визуально у потребителей меняется только шрифт (Manrope вместо системного) — это исправление, проверить снимками их страниц.

## Часть 2. «Стол» на системе (`monitoring`, после раскатки v0.5.0)

- `wall-main.tsx`: корень страницы стола получает `.vs-kiosk`; тема — тёмная из токенов (на странице стены и стола `color-scheme: dark` принудительно).
- `Desk.tsx` и `desk.css` пересобраны: режимы — `Segment`; «Войти» — `Button` primary; иконки музыки — `IconButton`; плитки — `Tile`; число агентов, минуты до встречи — `Stat`; списки агентов, новостей и календаря — `List`/`ListRow`. В `desk.css` остаётся только раскладка (grid-области по режимам) на токенах `--vs-space-*`; ни одного hex, px-размера текста и своего SVG.
- Шапка: слева `Segment` режимов, справа — `Banner` проблемы (если есть: «Мак не на связи с 14:02», «Мак недоступен») и часы. Отдельной полосы под шапкой нет.
- Иерархия:
  - встреча: `later` — плитка тихая, `Stat size="md"` со временем начала, без дубля времени в подписи; `soon` — `Stat size="xl"` минуты + `Button` «Войти»; `imminent` — `tone="warn"`; идёт без меня — `tone="danger"`; в эфире — `Stat muted` «осталось N мин»;
  - агенты: ждут 0 — плитка без крупного числа, строка «никто не ждёт · работают N»; ждут > 0 — `Stat tone="warn"` и `List` ждущих с `meta` «12 мин»;
  - музыка: обложка, трек, исполнитель, `IconButton` ×3; фоновое размытие обложки убрать (не системный приём).
- Раскладки (grid-области):
  - «Всё»/«Домлаб»: 3 колонки, верх — встреча · агенты · музыка, низ — новости (2 колонки) · календарь;
  - «Работа»/«Обучение»: якорь крупно в первой строке на всю ширину, ниже встреча и агенты в две колонки на всю оставшуюся высоту, музыка — строкой внизу;
  - «Отдых»: часы (`Stat` display) по центру вертикали, под ними музыка, агенты одной строкой — композиция центрирована.
- Новости и календарь на «Столе» — `List`/`ListRow` из данных `/api/briefing` и `/api/wall/agenda` (виджеты стены не встраиваются); теги новостей — `Chip`.
- Тесты: существующие сценарии `desk.test.tsx` остаются (классы заменяются на роли и `data-tile`); новый тест — в `desk.css` нет hex-цветов, `px`-размеров шрифта и `<svg` в `Desk.tsx`.
- Проверка вживую: снимки Pad 7 во всех режимах.
